# 汐見の家 — 意匠の基準

`style.css` 1枚で全ページの見た目を決めています。下層ページを作るときはこの文書と `index.html` を手本にしてください。**ページごとの CSS の書き足しは不要**という前提で組んであります。

## 1. 考え方

写真が主役です。木・障子・畳・庭の緑・瀬戸内の淡い水色・夜の灯り。意匠はその写真を邪魔しない「白い台紙」に徹します。

- 地は障子紙のような温かみのある白。真っ白にはしない（写真の木の色と喧嘩するため）
- 差し色は1色だけ。**汐の青**（瀬戸内の海の色）。リンク・ボタン・見出しの印・「ご予約」の枠に使う
- 緑は写真の中にあるので、意匠では足さない
- 文章は**すべて左揃え**。中央揃えにするものは無い
- 動きはリンクとボタンの色が変わるだけ。パララックスも自動で動くものも無い
- 写真の上に文字を置かない。写真の**下**に置く

## 2. 色

| 変数 | 値 | 使いどころ |
|---|---|---|
| `--paper` | `#fbfaf7` | ページの地 |
| `--paper-deep` | `#f3efe7` | 一段濃い地。フッター、補足の囲み `.notice` |
| `--ink` | `#2a2924` | 本文・見出し |
| `--ink-soft` | `#6a665e` | 補足、キャプション、日付 |
| `--rule` | `#e2ddd3` | 罫線 |
| `--shio` | `#2f6b87` | 差し色。リンク、ボタン、h2 の上の短い線、`.facts` の項目名 |
| `--shio-deep` | `#1f4f66` | マウスを乗せたときの色 |
| `--shio-pale` | `#e9f0f3` | 淡い青の地。「泊まりに来ませんか」の帯、`.notice-important` |

差し色 `--shio` はロゴの青 `#73C9E5` を、白地で文字が読める濃さまで落としたものです（ロゴの色そのままではコントラストが足りない）。ロゴの緑 `#9ED3BA` は意匠では使いません。写真の緑で足ります。

白ベースが施主の指定なので**ダークモードは作っていません**（`color-scheme: light` で固定）。

### ロゴ

`img/logo.svg`（カラー）をヘッダーに使います。ロゴは縦組み（マークの下に shiomi house）で、ヘッダーの高さでは英字が読めないため、右に**「古民家ゲストハウス／汐見の家」を文字で添えて**います（`.brand-name` と `.brand-sub`）。ロゴの `alt` は空にして、リンクの読み上げは添えた文字に任せています。`logo-mono.svg`（墨）と `logo-white.svg`（白抜き）は印刷物や濃い地に載せるとき用で、サイト上では使っていません。

## 3. 文字

OS に入っている書体だけを使います。Web フォントは読み込みません。

- **本文**：ゴシック。Mac は Hiragino Sans、Windows は BIZ UDPGothic → Yu Gothic Medium → Meiryo の順
- **見出し（h1・h2・特徴の見出し）**：明朝。Mac は Hiragino Mincho ProN、Windows は BIZ UDPMincho → Yu Mincho
- **h3・h4**：ゴシックの太字（明朝は小さくすると Windows で細くなるため）

大きさ。客層に合わせて標準より一段大きくしています。

| | スマホ | PC（56em ≒ 950px 以上） |
|---|---|---|
| 本文 | 17px | 18px |
| h1 | 約 30px | 40px |
| h2 | 約 26px | 32px |
| h3 | 1.2rem（約 20px） | 同 |
| キャプション・補足 | .875〜.9rem（15〜16px） | 同 |

行間は本文 1.9、見出し 1.45。字間は本文 .02em、見出し .06em。**13px 以下の文字は使いません**。

1行の長さは本文で **37rem（約36〜38字）** まで。文章を書く枡には `.prose` か `.wrap-text` を使うと自動でこの幅に収まります。

## 4. 余白

| 変数 | 値 | 使いどころ |
|---|---|---|
| `--gutter` | 20〜48px（画面幅に応じて） | 左右の余白。**どの幅でも 20px 以上**空く |
| `--space-section` | 56〜104px | 区画（`.section`）と区画の間 |
| `--space-5` | 4rem | 「よその宿には無いもの」の項目間（スマホ） |
| `--space-4` | 2.5rem | 見出しの上、区画内の大きな区切り |
| `--space-3` | 1.5rem | 見出しと本文の間、部品の内側 |
| `--space-2` | 1rem | ボタン同士の間など |

ページ全体の幅は `--width-page`（66rem ≒ 1190px）。ヒーロー写真だけ `.wrap-wide` で少し広く出ます。

## 5. 見出しの階層

1ページに h1 は1本。順序を飛ばさない。

| 要素 | 見た目 | 役割 |
|---|---|---|
| `h1` | 明朝・最大 | ページの題。トップではキャッチコピー、下層では `.page-head` の中に置く |
| `h2` | 明朝・**上に短い青い線** | 区画の見出し。`main` の中の h2 には自動で線が付く。トップでは `class="section-title"` を付けているが、下層では素の `<h2>` で同じ見え方になる |
| `h3` | ゴシック太字 | 区画の中の項目。特徴（`.feature h3`）だけは明朝 |
| `h4` | ゴシック太字・やや小 | h3 の中の細目。あまり使わない |

## 6. 部品の使い分け

### 骨組み

| クラス | 用途 |
|---|---|
| `.section` | 区画。上下に大きな余白。連続すると間が詰まりすぎないよう調整済み |
| `.wrap` | ページ幅の枡。ほぼ全部これで包む |
| `.wrap-text` | 文章専用の狭い枡（読み物の本文など） |
| `.wrap-wide` | 写真向けの少し広い枡（ヒーロー） |
| `.page-head` | 下層ページの先頭。`<h1>` と一言の `<p>` を入れる。下に罫線 |
| `.prose` | 本文の幅を文章向けに絞る。読み物や「汐見の家について」の長文に |
| `.breadcrumb` | パンくず。あれば付ける、なくても良い |

### 写真

| クラス | 用途 |
|---|---|
| `.hero-photo` | トップの顔写真。スマホは 4:3 の横幅いっぱい、PC は 2:1 で左右に余白 |
| `.feature` | 写真＋見出し＋説明を1組に。PC では写真と文章が左右交互に並ぶ。「部屋と設備」の設備紹介にも使える |
| `.media` / `.media-reverse` | 写真と文章を横に並べる（スマホでは縦）。`-reverse` で写真が右 |
| `.photo-grid` | 写真を並べる。幅に応じて 1〜3列。`<li><img><span>キャプション</span></li>` の形 |
| `.room-list` | `.photo-grid` に足すと、中くらいの幅でも3列を保つ |
| `.photo` | 1枚の写真を横幅いっぱいに |

写真は4サイズ書き出し済みなので `srcset` で出し分けます。書き方は `index.html` の `<img>` をコピーして、ファイル名だけ変えてください。ヒーロー以外は `loading="lazy"` を付けます。

```html
<img src="img/名前-1200.jpg"
     srcset="img/名前-480.jpg 480w, img/名前-800.jpg 800w, img/名前-1200.jpg 1200w, img/名前-1800.jpg 1800w"
     sizes="(min-width: 66em) 620px, (min-width: 48em) 58vw, 100vw"
     alt="日本語の説明" width="1200" height="800" loading="lazy">
```

`sizes` の目安：横幅いっぱいの写真は `100vw`、`.feature` は上の通り、`.photo-grid` は `(min-width: 66em) 360px, (min-width: 40em) 33vw, 100vw`、`.media` は `(min-width: 66em) 560px, (min-width: 48em) 55vw, 100vw`。

### 情報のかたまり

| クラス | 用途 |
|---|---|
| `.facts` | 項目名＋値の一覧を横に並べる（PC 3列・スマホ1列）。料金、定員、チェックイン、住所。`<dl class="facts"><div><dt>項目</dt><dd>値</dd></div>…</dl>` |
| `.facts-list` | 項目名＋説明を縦に並べる。ハウスルール、設備一覧 |
| `table` | 素の表でそのまま整う。スマホで幅が足りない表は `<div class="table-scroll">` で包む（表だけが横に動き、ページは動かない） |
| `.link-list` | 罫線で区切ったリンク一覧。読み物の目次。`<span class="link-title">` と `<span class="link-desc">` の2つを入れる。`<ol class="link-list">` にすると漢数字の番号が付く |
| `.media-list` | 日付・媒体名・一言の行。メディア掲載ページ。`<li><time>2018年4月</time><span class="eyebrow">愛媛新聞</span><span>見出し</span></li>` |
| `.timeline` | 時系列の記録。古民家再生の記録に。`<li><time>2012年</time><h3>…</h3><p>…</p></li>` |
| `.article` | 読み物1本。`<header>` に h1 と `.article-meta`（日付など）、下に本文。幅は文章向け |
| `.article-nav` | 連載の前後へのリンク行 |

### 強調と囲み

| クラス | 用途 |
|---|---|
| `.button` | 枠だけのボタン（二番手の行動） |
| `.button.button-primary` | 青く塗ったボタン（一番してほしい行動。1画面に1つ） |
| `.button-row` | ボタンを横に並べる行。スマホでは横幅いっぱいに |
| `.more` | 「〜を見る →」の1行リンク。区画の末尾に |
| `.cta` | 「泊まりに来ませんか」の淡い青の帯。1ページに1つ、末尾に |
| `.notice` | 補足の囲み（薄い茶の地） |
| `.notice-important` | 必ず読んでほしい注意（淡い青の地、左に青い線） |
| `.eyebrow` | 日付や区分の小さな文字 |

### 埋め込みとフォーム

| クラス | 用途 |
|---|---|
| `.embed` | Google マップや空室カレンダーの `<iframe>` を包む。iframe に `width="800"` が書いてあっても枡に収まり、横スクロールは起きない。縦長のカレンダーには `.embed-tall` |
| フォーム | `<label>`・`<input>`・`<select>`・`<textarea>` は素のまま整う。1項目を `<div class="form-row">` で包む。短い入力は `.form-row-short`、選択肢の並びは `.choice` |

## 7. 下層ページの型

```html
<main>
  <div class="wrap">
    <div class="page-head">
      <h1>部屋と設備</h1>
      <p>一言の説明（なくてもよい）</p>
    </div>
  </div>

  <section class="section">
    <div class="wrap">
      <h2>区画の見出し</h2>
      <div class="prose">
        <p>本文。</p>
      </div>
    </div>
  </section>

  <section class="section cta">
    <div class="wrap">
      <h2>泊まりに来ませんか</h2>
      <p>…</p>
      <p class="button-row"><a class="button button-primary" href="/reserve/">予約・お問い合わせ</a></p>
    </div>
  </section>
</main>
```

ヘッダーとフッターは `index.html` からそのままコピーします（ロゴのマークと「古民家ゲストハウス／汐見の家」の文字も含めて）。下層ページは1階層深い場所（`/about/index.html` など）に置くので、**CSS と画像のパスは `../style.css`、`../img/…` に直す**こと。ナビの現在ページには `<a href="/rooms/" aria-current="page">` を付けると青い下線が付きます。

## 8. 守っていること（下層でも崩さない）

- 横スクロールは起きない（`html`/`body` で封じ、画像・iframe・表にも個別に手当て）
- 文章と箇条書きは左揃え
- 本文 17px 以上、キャプションでも 15px を下回らない
- 写真の上に文字を置かない
- 外部読み込み無し（フォント・CDN・アイコン）。JavaScript 無し
- 動きはリンクとボタンの色変化だけ。`prefers-reduced-motion` ではそれも止まる
- 印刷するとナビ・ボタン・予約の帯が消え、本文と写真だけになる
