# 画像素材

## ロゴ

元データは受領した `shiomihouse_logo_fix.ai`（Illustrator）。

| ファイル | 用途 |
|---|---|
| `logo.svg` | カラー版。マークは緑→青の縦グラデーション、文字は緑→青の横グラデーション |
| `logo-mono.svg` | 墨一色（`#3E3938`） |
| `logo-white.svg` | 白抜き。濃い背景に載せる用 |

いずれもベクター。48pxまで縮めても破綻しないことをChromiumで確認済み。

**ロゴ由来の色**（施主の「青か緑が好き」は、すでに自分のロゴに入っている）

- 緑 `#9ED3BA`
- 青 `#73C9E5`
- 墨 `#3E3938`

いずれも淡いので、本文やリンクにそのまま使うとコントラストが足りない。
文字用には暗い派生色を別に用意すること。

## 写真

`manifest.json` に全点の用途名・日本語alt・元ファイル名・書き出しサイズ。
各カット最大4サイズ（`-480` `-800` `-1200` `-1800`）。srcset で出し分ける。

### 出所と制約

- 受領素材66点から37点を採用
- **人物が写ったもの**：浴衣の宿泊客2名のカット3枚（`guests-*`）は**掲載許諾あり**。
  子供が写ったカット、犬と一緒のカットは**許諾が無いため不採用**
- **食事**：`meal-table` は受領した `4545.jpg` を明るさとトリミングのみ補正したもの。
  同時に受領した生成画像3枚は、実際の料理と細部が異なるため不採用
  （元画像が1536x1152しかなく、寄ったトリミングは解像度が足りないため全景のみ）
- `meal` は現行サイトにあった「開業祝いの膳」
