# SEOの方針

2026-09-15。

## 前提：「佐島 ホテル」では誰も探さない

佐島という地名が、まず知られていない。
知らない地名は検索されないので、そこを狙っても人は来ない。

では、この宿に泊まる人は、どういう言葉でインターネットを見ているか。

| 人 | 検索しそうな言葉 |
|---|---|
| しまなみ海道を自転車で走る人 | しまなみ海道 宿／しまなみ 島 泊まる／ゆめしま海道 |
| ゆめしま海道を目当てに来る人 | ゆめしま海道 サイクリング／ゆめしま海道 宿泊／岩城橋 |
| 弓削高校・弓削商船高専に用のある人 | 弓削高校 島留学 保護者／弓削商船 オープンキャンパス 宿 |
| 瀬戸内で古民家に泊まりたい人 | 瀬戸内 古民家 ゲストハウス／愛媛 古民家 宿 |
| 珍しいものを探している人 | 五右衛門風呂 泊まれる／井戸 手押しポンプ 宿 |
| 日系移民のことを調べている人 | 日系一世／強制収容所／ロバート汐見 |

**佐島という地名を覚えてもらうのは、来たあとでいい。**
先に「ここへ来る理由」の方から入ってきてもらう。

## やったこと

**タイトルと説明文**
旧サイトは `<title>` が1本も入っていなかった。全45ページに入れ直し、
文言は `content/seo.json` に集めた。`apply-seo.py` で当てる。

**構造化データ（JSON-LD）**

| 種類 | 入れたページ |
|---|---|
| LodgingBusiness | トップ（住所・電話・料金・チェックイン時刻・設備） |
| WebSite | トップ |
| BreadcrumbList | 下層ページすべて |
| Article | 読み物の各記事（著者・掲載日・連載名） |
| FAQPage | `/faq/` の16問 |

FAQPage は、検索結果の中で答えがそのまま出ることがある。
生成AIが宿のことを答えるときにも、ここが引かれやすい。

**サイトマップと robots.txt**
`sitemap.xml`（42URL）と `robots.txt` を自動で書き出す。
noindex にしたページ（送信完了画面など）は入らない。

**OGP**
全ページにOGP画像・タイトル・説明文。SNSやLINEで貼られたときに
ちゃんと見えるように。

**旧URLからの301**
152URLすべてを検討し、108本を301で新URLへ送る。
旧サイトが集めてきた評価を、新しいページに引き継ぐため。

## 公開したあとにやること

1. **Google Search Console** にサイトを登録し、`sitemap.xml` を送信する
2. **Googleビジネスプロフィール**（旧マイビジネス）を整える
   — 地図に出る宿の情報。写真と営業情報を入れておくと、
   「上島町 宿」のような検索で地図の枠に出やすくなる
3. 301が効いているか、旧URLをいくつか踏んで確かめる
4. 2〜3か月後に Search Console で、どの言葉で来ているかを見る
   — 想定と違う言葉で来ていたら、そこに合わせてページを足す

## まだできていないこと

- **緯度経度**（構造化データの `geo`）。正確な値をいただければ入れる。
  地図の検索結果に出やすくなる
- **口コミ**。Googleの口コミが増えると地図での順位が上がる。
  泊まった方にお願いするのが、いちばん効く
- **他のサイトからのリンク**。上島町の観光サイト、ゆめしま海道の
  サイクリング情報サイト、弓削高校の島留学の案内などから
  リンクしてもらえると強い

## 効くまでの時間

新しいページが検索に出てくるまで、だいたい2週間から1か月。
順位が落ち着くまで3か月ほど見てください。
公開直後に順位が出ないのは、普通のことです。
