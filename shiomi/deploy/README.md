# 納品と切り替え

## 中身

| ファイル | 説明 |
|---|---|
| `htaccess.txt` | サーバーに上げるときに **`.htaccess`** にリネームする。301リダイレクト110本を含む |
| `redirects.csv` | 旧152URLの行き先一覧。目視確認用 |

## 301の設計

| 分類 | 件数 | 行き先 |
|---|---|---|
| ロバート汐見の足跡 | 24 | `/stories/shiomi/` 配下に1:1（英語版9本も対応する日本語ページへ） |
| 古民家再生 | 16 | `/stories/renovation/` にアンカー付きで統合 |
| 島の暮らし | 6 | `/stories/island/` にアンカー付きで統合 |
| メディア掲載 | 19 | `/media/` に集約 |
| 宿の紹介・部屋・食事 | 16 | `/about/` `/rooms/` `/meals/` `/thanks/` |
| アクセス | 18 | `/access/` |
| ご予約 | 2 | `/reserve/` |
| その他 | 9 | トップまたは `/stories/` |
| **受け皿なし（404）** | **41** | 終了したイベント告知、節目の挨拶、終了した寄付企画 |

152URL すべてについて、意図した行き先に解決することを正規表現レベルで検証済み
（Apache実機での確認ではない。本番反映後に実地で抜き取り確認すること）。

## 切り替えの順番

1. 独自SSLを有効化する（先方作業）
2. 静的ファイル一式をドキュメントルートに上げる
3. `htaccess.txt` を `.htaccess` にリネームして設置
4. 抜き取りで301を確認する（特に `/166/` `/1331/` `/en/514/` `/media/` あたり）
5. 問題がなければ `.htaccess` の【HTTPS】ブロックのコメントを外す
6. サーチコンソールで新しいサイトマップを送信
7. **ここまで確認できてから** WordPress（`/wp/`）を撤去する

### WordPress撤去前に必ず

サーバー上の画像679点を退避しておくこと。`/wp/wp-content/uploads/` 配下にあり、
撤去すると取得できなくなる。（本セッションで取得済み）

## 記録：英語版について

英語版は廃止と決定（外国人客はAirbnbで受けるため）。

ただし調査の過程で、**ロバート汐見の連載は英語版も全9本が完訳されており、
各4,000〜5,800字と日本語版より長い**ことが分かった。廃止の判断は変えないが、
翻訳という資産が存在した記録として残す。将来必要になった場合、
本セッションで取得した生HTMLから復元できる。
