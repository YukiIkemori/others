# このサイトを預かるAIへ

古民家ゲストハウス「汐見の家」（愛媛県上島町佐島）のウェブサイトです。
2026年9月に、WordPressから静的HTMLへ作り直しました。
この文書は、これから文言や写真の手直しをするあなたへの申し送りです。

**お願いする相手は、ウェブに詳しくない方です。**
「ここを直せば直ります」と、ファイル名と該当の文を示して案内してください。
FTPソフト（FileZilla）でファイルを上げ下げできる、という前提で結構です。

---

## 1. いちばん大事なこと

### HTMLが正本です

このサイトは、もともとPythonの生成スクリプトから書き出しました。
**そのスクリプトは同梱していません。** 手直しが全部消える事故を防ぐためです。

いま手元にあるHTMLファイルが唯一の正本です。文言を直すときは、
**HTMLファイルを直接開いて、文字のところだけ書き換えてください。**

### 守っていただきたい決めごと

このサイトは、次の方針で作られています。崩さないでください。

| 決めごと | 理由 |
|---|---|
| **JavaScriptを使わない** | 1行も入っていません。動きはすべてCSSで作っています。追加すると、この設計の一貫性が崩れます |
| **外部から何も読み込まない** | ウェブフォント、CDN、アイコンライブラリ、アクセス解析、いずれも使っていません。表示が外部サービスの都合に左右されず、個人情報も外に出ません |
| **CSSは `style.css` の1枚だけ** | 45ページすべてがこれ1枚を見ています。ここを直すと全ページに影響します |
| **ページ間のリンクは `/about/` のようにルートから書く** | ドメインの直下に置く前提です。サブフォルダに移すと全部壊れます（後述） |
| **画像とCSSは `../img/` のように相対で書く** | 階層の深さに応じて `../` の数が変わります。ここを間違えると画像が出なくなります |

### 触ってはいけないもの

- `style.css` の構造（色や余白の変数）— 見た目の決めごとは `見た目の決めごと.md` にあります
- `<head>` の中の `<script type="application/ld+json">` — 検索エンジン向けの情報です。料金や定員を直したら、ここも合わせてください（`index.html` にあります）
- `.htaccess` — 旧サイトのURLから新URLへの転送が108本入っています。消すと、これまで検索やSNSから来ていた人が迷子になります
- `sitemap.xml` `robots.txt` — 検索エンジン向け

## 3. 文言を直すとき

### 手順

1. `文言の置き場所.md` で、直したい文があるファイルを探す
2. そのHTMLをテキストエディタで開く
3. `<` と `>` で囲まれた部分は触らず、**文字のところだけ**書き換える
4. **UTF-8** で保存する（文字コードを変えないこと）
5. FTPでそのファイルだけ上げ直す
6. ブラウザで見て確かめる

### 全ページに入っている文言

宿の名前、住所、電話番号、フッターの文、メニューの並びなどは
**45ファイルすべてに同じ文が入っています。**
1か所だけ直すと食い違うので、フォルダ内を一括置換してください。
どれが該当するかは `文言の置き場所.md` の最後にまとめてあります。

### 料金や定員を直すとき

次の場所に散らばっています。**全部揃えてください。**

- `index.html` — 「宿のあらまし」の表、および `<head>` の構造化データ
- `about/index.html` — 「料金」の表
- `reserve/index.html` — 「料金」の表、フォームの選択肢の説明
- `faq/index.html` — 「料金はいくらですか。」の答え、および `<head>` の構造化データ
- `school/index.html` — 本文
- 各ページの `<head>` の `<meta name="description">` と `<meta property="og:description">`

### 見出しやタイトルを直すとき

`<title>` を直したら、同じページの `<meta property="og:title">` も
同じ文言に揃えてください。SNSに貼られたときの見出しです。
`<meta name="description">` と `<meta property="og:description">` も同様です。

## 4. 写真を差し替えるとき

写真は1枚につき4つの大きさを用意しています。

```
img/goemon-bath-480.jpg   スマホ用
img/goemon-bath-800.jpg
img/goemon-bath-1200.jpg
img/goemon-bath-1800.jpg  PC用
```

HTMLではこう書かれています。

```html
<img src="../img/goemon-bath-1800.jpg"
     srcset="../img/goemon-bath-480.jpg 480w, ... 1800w"
     sizes="..." alt="五右衛門風呂" width="1800" height="1200" loading="lazy">
```

差し替えるときは、**同じ名前で4つの大きさを作って上書き**してください。
1枚だけ差し替えると、画面の大きさによって古い写真が出ます。

- `width` と `height` は、1800px版の実際の縦横を入れてください。
  ここが実物と違うと、読み込み中にページがガタつきます
- `alt` は写真の説明です。目の見えない方が読み上げで聞く文です。必ず書いてください
- `loading="lazy"` は残してください（最初の1枚だけ付いていません。それでよいです）

## 5. 直したあとの確認

**必ずこの5つを見てください。**

1. **スマホの幅（390pxくらい）で横にはみ出していないか**
   ブラウザの開発者ツールで幅を390pxにして、横スクロールバーが出なければOK
2. **リンクが切れていないか**
   直したページのリンクをひととおり押してみる
3. **写真が出ているか**
   特に階層の深いページ（`stories/renovation/ido/` など）。`../` の数を間違えやすい
4. **文字化けしていないか**
   保存の文字コードがUTF-8になっているか
5. **問い合わせフォームが動くか**（フォーム周りを触ったとき）
   自分宛に1通送ってみる

## 6. 問い合わせフォームについて

`reserve/send.php` がメールを送ります。PHPの標準機能だけで動きます。

**公開前に必ず、`FROM_ADDR` を実在するアドレスに変えてください。**
詳しくは `問い合わせフォームの設置.md` を読んでください。

迷惑メール対策として、見えない入力欄・連投よけ・本文のURL数・
メールヘッダへの改行混入よけを入れてあります。外さないでください。

## 7. やってはいけないこと

| してはいけないこと | 何が起きるか |
|---|---|
| サブフォルダ（`/test/` など）に移す | ページ間のリンク2,021箇所とリダイレクト110本が全部壊れます。**必ずドメインまたはサブドメインの直下に置いてください** |
| `.htaccess` を消す・書き換える | 旧サイトのURLからの転送が止まり、検索やSNSから来た人が404になります |
| JavaScriptを足す | この設計の一貫性が崩れます。動きが必要なら、まずCSSでできないか考えてください |
| ウェブフォントやCDNを足す | 表示が外部サービス任せになります |
| 画像を1つの大きさだけ差し替える | 画面の大きさによって古い写真が出ます |
| `style.css` を大きく書き換える | 45ページ全部に影響します。触る前に `見た目の決めごと.md` を読んでください |
| 文字コードをShift_JISで保存する | 全部文字化けします |

## 9. 元のサイトとの照合について

このサイトの文言は、旧サイト152ページを引き直して突き合わせてあります。
読み物42本は元記事の本文をそのまま載せています（書き換えていません）。

固定ページの文章は書き起こしたものですが、
**元サイトに根拠のない記述は落としてあります。**
新しく事実を書き足すときは、必ず宿の方に確認してください。
「たぶんこうだろう」で書かないでください。実際、それで一度やり直しました。

照合の記録は `文言の確認事項.md` にあります。
