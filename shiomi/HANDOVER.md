## 1. 決まったこと

- **全ページ静的HTML。** WordPress は使わない
- **ブログは作らない。** 先方と交渉して落とした（2026-09-15）
- **CMS・CI・自動デプロイは組まない。** 年に数回しか更新しないサイトに過剰
- **納品は FileZilla などで さくらに手上げ。** GitHub Actions も Secrets も使わない
- **Firebase は使わない。** 一度 `shiomi-test` プロジェクトを作ったが不使用に決定。放置か削除でよい
- **先方確認は、HTMLファイルを渡すかスクショで行う。** テスト用URLは立てない
- フロントの意匠は **フェーブル（Fable）** に投げる。ただし「装置を指定しない。避けるものと動作条件だけ渡す」

## 4. 次にやること

1. **サイト全ページをクロールして棚卸し。** URL・ステータス・title・description・h1・本文・
   画像・リンク構造。HTTPSの有無とリダイレクトも確認する
2. **料金を特定する**
3. **旧URL→新URLの301マッピングを設計。** 数字IDの記事のうち、中身が資産のもの
   （ロバート汐見の話、古民家再生の記録、メディア掲載）は静的ページに移植して301を向ける。
   残りは404でよい。`.htaccess` 1枚にまとめて納品する
4. **サーチコンソールを登録。遡らないので着手前に入れるほど「前」のデータが貯まる**
5. ページ構成案 → フェーブルに意匠を投げる
6. 納品：HTML一式＋`.htaccess`。FileZillaでさくらへ
