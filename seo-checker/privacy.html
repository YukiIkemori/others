プライバシーポリシー

制定日: 2026/11/13

SEOチェッカー（以下「当サイト」）における情報の取り扱いについて説明します。当サイトは会員登録を必要とせず、氏名やメールアドレスなどの個人情報を収集しません。

当サイトが保存する情報

診断の処理はお使いのブラウザの中で実行されます。入力された URL や診断結果を、当サイトがデータベースなどに保存することはありません。

ブラウザの保存領域（ローカルストレージ）には、次の設定だけを保存します。これらはお使いの端末の中にとどまり、当サイトには送信されません。ブラウザのサイトデータを削除すると消去されます。

  • 速度計測の対象（モバイル・PC・計測しない）
  • サイト全体診断の最大ページ数
  • ご自身で入力した PageSpeed API キーと取得プロキシの URL（入力した場合のみ）

当サイトは Cookie を使用していません。アクセス解析ツールや広告も設置していません。

診断のために外部へ送信される情報

診断を実行すると、入力された URL が次の送信先に送られます。

送信先目的送信される情報
当サイトの中継機能（Cloudflare 上で動作）診断対象のページ、robots.txt、サイトマップの取得と、リンク先の確認診断対象の URL、ページ内のリンクの URL
Google PageSpeed Insights表示速度の計測診断対象の URL
Google Public DNSDNS 設定の確認診断対象のドメイン名
診断対象のサイトSNS 表示プレビューの画像の表示画像の取得に伴う通常のアクセス情報（IP アドレスなど）

当サイトの中継機能が利用できない場合に限り、ページの取得に第三者が運営する公開プロキシ（cors.lol、AllOrigins、CodeTabs、corsproxy.io）を使用することがあります。この場合、診断対象の URL がこれらのサービスに送信されます。

各サービスに送信された情報は、それぞれの事業者のプライバシーポリシーに従って取り扱われます。ログインが必要なページや、外部に知られたくない URL は診断しないでください。

アクセスログ

当サイトは Cloudflare のサービス上で配信されています。配信にあたり、Cloudflare が IP アドレスやアクセス日時などの情報を、同社のポリシーに従って処理します。当サイトの運営者が、これらの情報を個人の特定に使用することはありません。

免責事項

診断結果は、一般的な SEO の推奨事項にもとづく目安です。内容の正確性や、検索順位の向上を保証するものではありません。診断結果を利用したことで生じた損害について、当サイトは責任を負いません。

改定

このポリシーの内容は、機能の追加や変更に応じて改定することがあります。改定後の内容は、このページに掲載した時点から適用されます。
