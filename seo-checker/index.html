診断する内容

  • 基本メタ情報タイトルと説明文の長さ・重複、canonical、viewport、言語、文字コード
  • コンテンツH1 と見出しの階層、文章量、頻出語とタイトルの一致、運営者情報への導線
  • クロール・インデックスnoindex、robots.txt、XML サイトマップ、URL 構造、リダイレクト、hreflang
  • リンク・画像内部リンク、アンカーテキスト、alt 属性、画像サイズ指定、遅延読み込み
  • SNS・構造化データOGP、X カード、JSON-LD の構文と必須項目
  • 技術・セキュリティHTTPS、混在コンテンツ、描画ブロック、DOM サイズ、ヘッダー、DNS
  • 表示速度Google PageSpeed Insights による Core Web Vitals と Lighthouse 評価

診断はすべてお使いのブラウザ内で実行され、入力した URL や結果がこのサイトのサーバーに保存されることはありません。ページの取得には取得用プロキシを、速度計測には Google PageSpeed Insights を、DNS の確認には Google Public DNS を利用します。スコアは一般的な SEO のベストプラクティスに基づく目安であり、検索順位を保証するものではありません。
