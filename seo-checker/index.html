無料のSEOチェックツール
URLを入れるだけで約70項目を採点

SEOチェッカーは、ページの SEO を多角的に診断する無料ツールです。メタ情報・見出し・クロール設定・リンク切れ・構造化データ・表示速度までを確認し、100点満点の点数と優先度順の改善点を表示します。登録不要で、サイト全体の診断にも対応しています。

設定・うまく取得できないとき
速度計測の対象

速度計測が混雑で失敗するときに。Google で無料発行でき、このブラウザ内にだけ保存されます。

同梱の Cloudflare Worker を置いた場合に指定すると、レスポンスヘッダーやリダイレクトも診断できます。

SEOチェッカーの使い方

  1. URL を入力する診断したいページの URL を入力欄に貼り付けます。「https://」は省略できます。
  2. 診断範囲を選ぶ1ページを詳しく調べるなら「このページだけ」、サイト全体の問題を探すなら「サイト全体」を選びます。
  3. 結果を見て直す点数と、優先度順に並んだ改善点が表示されます。上から順に対応すると、効果の大きい問題から解消できます。

SEOチェックで診断する内容

検索エンジンに正しく読まれ、検索結果で選ばれるために必要な項目を、7つの分野から確認します。項目の一覧は「SEOチェックリスト70項目」に掲載しています。

  • 基本メタ情報タイトルとメタディスクリプションの長さ・重複、canonical、viewport、言語、文字コード
  • コンテンツH1 と見出しの階層、文章量、頻出語とタイトルの一致、運営者情報への導線
  • クロール・インデックスnoindex と robots.txt、XML サイトマップ、URL 構造、リダイレクト、hreflang
  • リンク・画像リンク切れ、内部リンク、アンカーテキスト、alt 属性、画像サイズ指定、遅延読み込み
  • SNS・構造化データOGP、X カード、JSON-LD の構文と必須項目
  • 技術・セキュリティHTTPS、混在コンテンツ、描画ブロック、DOM サイズ、セキュリティヘッダー、DNS
  • 表示速度Google PageSpeed Insights による Core Web Vitals と Lighthouse 評価
  • サイト全体診断最大50ページを巡回し、タイトル・説明文の重複、内部リンク切れ、エラーページ、サイトマップの不整合を横断チェック

点数と評価の見方

分野ごとに100点満点で採点し、重要度に応じて重み付けした総合点を表示します。noindex など検索結果に表示されなくなる問題がある場合は、総合点を45点までに制限します。

評価点数状態の目安
S95点以上ほぼ万全。細かな改善点だけが残っている
A85〜94点良好。いくつかの項目を直せば万全になる
B70〜84点基本はできている。改善すると効果が出やすい
C55〜69点重要な項目に不足がある
D40〜54点基本的な対策が不足している
E39点以下検索エンジンに正しく読まれていない可能性が高い

こんなときに使えます

  • ページを公開する前の最終確認。noindex の消し忘れや、タイトル・OGP の設定漏れを見つけられます。
  • サイトをリニューアルした後の確認。リンク切れ、リダイレクトの連鎖、サイトマップの不整合をまとめて調べられます。
  • 検索に出てこない原因の調査。インデックスを妨げている設定がないかを確認できます。
  • 制作会社や社内への報告。診断結果をテキストや PDF で書き出し、そのまま共有できます。

よくある質問

無料で使えますか？回数の制限はありますか？

すべての機能を無料で使えます。会員登録は不要で、診断回数の制限もありません。

自分のサイト以外も診断できますか？

公開されているページであれば診断できます。ただし診断のために対象サイトへ自動でアクセスするため、ご自身が管理するサイトか、診断の許可を得ているサイトでご利用ください。ログインが必要なページは取得できません。

点数が高ければ検索順位は上がりますか？

点数は、検索エンジンに正しく読まれるための技術的な土台が整っているかを示す目安です。検索順位は、内容が検索した人の役に立つかどうかや、ほかのサイトからの評価にも左右されるため、点数だけで順位が決まるわけではありません。まず土台の問題をなくし、そのうえで内容を充実させるのが近道です。

1ページ診断とサイト全体診断の違いは何ですか？

1ページ診断は、指定したページを約70項目で詳しく調べ、表示速度も計測します。サイト全体診断は、サイトマップと内部リンクから最大50ページを巡回し、タイトルの重複や内部リンク切れなど、複数のページを見比べないと分からない問題を検出します。

表示速度が「対象外」と表示されるのはなぜですか？

表示速度の計測には Google PageSpeed Insights を利用しています。無料の共有枠が混雑していると計測できないことがあります。時間をおいて再度お試しいただくか、「設定」に Google で無料発行できる API キーを入力すると安定して計測できます。

入力した URL や診断結果は保存されますか？

診断はお使いのブラウザの中で実行され、URL や結果が当サイトに保存されることはありません。ページの取得と速度計測のために、URL が当サイトの中継機能と Google のサービスに送信されます。詳しくはプライバシーポリシーをご覧ください。

ページを取得できないと表示されます。

対象サイトが自動アクセスを拒否している、ログインが必要、アクセスが集中している、などの原因が考えられます。「設定」を開き、ブラウザで表示したページのソースを貼り付けると、取得できないページも診断できます。

SEOガイド

診断項目の意味と直し方を、項目別に解説しています。

  • SEOチェックリスト：公開前に確認したい70項目
  • タイトルタグの最適な文字数と書き方
  • メタディスクリプションの書き方と文字数の目安
  • noindex と robots.txt の違いと使い分け
  • リンク切れの調べ方と直し方
  • Core Web Vitals（LCP・INP・CLS）の基準と改善方法
  • 構造化データ（JSON-LD）の基本と書き方

診断はすべてお使いのブラウザ内で実行され、入力した URL や結果がこのサイトに保存されることはありません。点数は一般的な SEO の推奨事項にもとづく目安であり、検索順位を保証するものではありません。詳しくは「このサイトについて」をご覧ください。
