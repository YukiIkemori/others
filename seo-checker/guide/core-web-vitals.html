Core Web Vitals（LCP・INP・CLS）の基準と改善方法

公開日: 2026/11/13　SEOチェッカー 編集部

Core Web Vitals（コアウェブバイタル）は、ページの表示速度や操作のしやすさを数値で表した、Google の3つの指標です。検索順位を決める要素のひとつとして使われています。このページでは、各指標の意味と合格ライン、改善方法を解説します。

3つの指標と合格ライン

指標測るもの良好改善が必要不良
LCPメインの内容が表示されるまでの時間2.5秒以内4.0秒以内4.0秒超
INP操作してから画面が反応するまでの時間200ミリ秒以内500ミリ秒以内500ミリ秒超
CLS読み込み中に起きるレイアウトのずれ0.1以下0.25以下0.25超

判定には、訪問者の75%が体験した値（75パーセンタイル）が使われます。平均値ではないので、一部の遅い環境での体験も結果に影響します。

実測値とラボ値の違い

Core Web Vitals には2種類のデータがあります。

  • 実測値（フィールドデータ）。Chrome を使う実際の訪問者から集めた過去28日間のデータです。Google が検索の評価に使うのはこちらです。
  • ラボ値。決まった条件でページを1回読み込んで測った値です。Lighthouse や PageSpeed Insights の「パフォーマンスの問題を診断する」がこれにあたります。

アクセス数の少ないページには実測値がありません。その場合はラボ値を参考にします。また、INP は実際の操作がないと測れないため、ラボでは代わりに TBT（Total Blocking Time）を見ます。TBT が大きいページは、INP も悪くなりやすい傾向があります。

SEOチェッカーは、PageSpeed Insights から実測値とラボ値の両方を取得し、実測値がある場合はそちらを重く評価しています。

LCP の改善方法

LCP は、多くのページで最上部の大きな画像か、見出しのテキストが対象になります。

  • メイン画像を軽くする。表示サイズに合わせて縮小し、WebP や AVIF に変換します。
  • メイン画像を遅延読み込みしない。最上部の画像に loading="lazy" を付けると、かえって遅くなります。fetchpriority="high" を付けて優先的に読み込ませます。
  • サーバーの応答を速くする。キャッシュや CDN を使い、HTML が届くまでの時間を短縮します。
  • 描画を止めるファイルを減らす。head 内のスクリプトには defer か async を付け、使っていない CSS を削除します。
  • ウェブフォントの読み込みを見直す。font-display: swap を指定し、フォントが届く前でも文字が表示されるようにします。

INP の改善方法

INP は、クリックやタップ、キー入力に対する反応の遅さを測ります。原因のほとんどは JavaScript です。

  • 使っていない JavaScript を削除する。読み込むだけで処理時間がかかります。
  • 外部のタグを減らす。広告、計測、チャット、SNS の埋め込みは、積み重なると大きな負荷になります。必要なものだけを残します。
  • 長い処理を分割する。50ミリ秒を超える処理は、途中で画面の更新を挟めるように分けます。
  • DOM を小さくする。要素数が多いと、操作のたびに再計算に時間がかかります。

CLS の改善方法

CLS は、読んでいる途中で内容が下にずれたり、押そうとしたボタンが動いたりする現象を数値にしたものです。

  • 画像と動画に width と height を書く。読み込み前から表示領域が確保され、後からずれなくなります。
  • 広告や埋め込みの領域を先に確保する。CSS で高さを指定しておきます。
  • ページの上部に後から要素を挿入しない。お知らせのバナーなどは、領域を確保しておくか、内容に重ねて表示します。
  • ウェブフォントによるずれを抑える。代替フォントとの大きさの差が小さくなるように調整します。

どこから手を付けるか

  1. 実測値で「不良」の指標から直す。検索の評価に使われているのは実測値です。
  2. テンプレート単位で直す。同じ作りのページは同じ問題を抱えています。1か所の修正が全ページに効きます。
  3. スマートフォンを優先する。Google はスマートフォン向けのページを基準に評価します。回線も処理能力もパソコンより厳しい条件です。

なお、Core Web Vitals は検索順位を決める多くの要素のひとつです。内容が検索意図に合っているかどうかのほうが影響は大きく、速度だけを改善しても順位が大きく上がるとは限りません。内容が同程度のページ同士で差がつく要素、と考えるのが実態に近いでしょう。
