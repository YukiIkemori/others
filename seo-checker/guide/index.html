SEOガイド：内部対策の基本を項目別に解説

SEOチェッカーが診断している項目について、なぜ重要なのか、どう直せばよいのかを項目別に解説しています。診断結果で指摘された項目から読むと、すぐに改善に取りかかれます。

  • SEOチェックリスト：公開前に確認したい70項目タイトルやメタ情報、見出し、クロール設定、リンク、構造化データ、表示速度まで、ページ公開前に確認したい内部SEOのチェック項目を7分野・約70項目の一覧にまとめました。優先順位の付け方も解説します。
  • タイトルタグの最適な文字数と書き方タイトルタグ（title）の文字数の目安は全角30文字前後です。検索結果で省略されない長さ、キーワードの置き方、ページごとに変えるべき理由、よくある失敗と確認方法を具体例つきで解説します。
  • メタディスクリプションの書き方と文字数の目安メタディスクリプション（meta description）は検索結果の説明文になる要素です。文字数の目安は全角70〜120文字。クリックされやすい書き方、例文、設定しても表示されない理由、確認方法を解説します。
  • noindex と robots.txt の違いと使い分けnoindexは「検索結果に出さない」、robots.txtは「クロールさせない」ための設定で、役割が違います。両方を同時に使うと逆効果になる理由、正しい使い分け、ページが検索に出ないときの確認手順を解説します。
  • リンク切れの調べ方と直し方リンク切れ（404エラー）はユーザーの離脱とクロールの無駄につながります。リンク切れが起きる原因、無料ツールでの調べ方、内部リンク・外部リンクそれぞれの直し方、301リダイレクトの使い方を解説します。
  • Core Web Vitals（LCP・INP・CLS）の基準と改善方法Core Web VitalsはGoogleがページ体験の評価に使う3つの指標です。LCPは2.5秒以内、INPは200ミリ秒以内、CLSは0.1以下が合格ライン。各指標の意味、実測値とラボ値の違い、原因別の改善方法を解説します。
  • 構造化データ（JSON-LD）の基本と書き方構造化データは、ページの内容を検索エンジンに正確に伝えるための記述です。JSON-LDの書き方、よく使うスキーマ（パンくず・記事・商品・組織）の例、必須項目、よくあるエラーと確認方法を解説します。
