# 日本語テキスト表記ガイド（ルミナス・クレスト）

対象プレイヤーは20歳以上。見た目はSFC風でも、**テキストは現代の読みやすい漢字かな交じり文**にする。
ひらがな・カタカナだけのオールドスタイルは禁止。

## 基本ルール
- 常用漢字は積極的に使う（例：「たからばこを あけた」→「宝箱を開けた」）。難読語・当て字だけはひらく。
- **分かち書き（DQ式のスペース区切り）はしない**。句読点「、」「。」を普通に使う。
  文中で「！」「？」の後に文が続くときは全角スペースを1つ入れる（例：「よくぞ参った！　勇者たちよ。」）。
- 数字は半角（「12のダメージ」「300ゴールド」）。
- NPCのセリフは話者名なし・かぎかっこなしでセリフ本文のみ（DQ式）。キャラクターの口調は保つ
  （王：〜じゃ、兵士：〜であります、老人：〜じゃよ 等）。
- 1行はメッセージウィンドウ幅（全角約21文字）に収まるよう、長い文は `\n` で改行する。4行で1ページ、`\f` で改ページ。

## 主人公の名前（プレイヤーが変更できる）
名前は**絶対に直書きしない**。表示時に置き換わるプレースホルダーを使う。
- `{yuki}` = ユウキ（男・剣士の家系の少年）
- `{non}` = ノン（女・神殿で育った心やさしい少女）
- `{metem}` = メテム（女・魔法学院の天才少女）
- `{leader}` = 先頭にいる生存メンバーの名前
性別・性格・口調は固定。戦闘やメニューのコードは `c.name` を使えば自動で反映される。

**コマンド**：戦う／オート／逃げる、戦う／（ジョブコマンド）／（サブ）／防御／道具。
**メニュー**：道具／アビリティ／装備／ジョブ／セット／強さ／並び替え／図鑑／地図／セーブ／設定。
アビリティの種類：アクション／リアクション／サポート／フィールド。サブアクション。
**装備欄**：武器／盾／頭／体／アクセサリ。
**能力値**：最大HP／最大MP／力／体力／素早さ／知力／精神／運、攻撃力／守備力／魔力／魔法防御／命中／回避／会心。

**状態**：毒／眠り／麻痺／混乱／沈黙／暗闇／即死／再生（「リジェネ」は使わない）。

## 定型メッセージ例
- 「{yuki}の攻撃！」「スケルトンに24のダメージ！」「スケルトンを倒した！」「魔物たちをやっつけた！」
- 「それぞれ120ポイントの経験値を獲得！」「{metem}はレベル12に上がった！」
- 「{non}の僧侶のジョブレベルが3に上がった！」「新しいジョブ『ナイト』になれるようになった！」
- 「{leader}は宝箱を開けた！　薬草を手に入れた！」「鍵がかかっている。」
- 「いらっしゃいませ！　何をお求めですか？」「ひと晩8ゴールドです。お泊まりになりますか？」

## 固有名詞の権利
ドラクエ・FF固有の呪文名・モンスター名・ジョブ名（メラ、ホイミ、ルーラ、スライム、ケアル、ファイガ、エスナ、
レイズ、リジェネ、白魔道士 等）は使わない。一般的なファンタジー語（ファイアボール、ヒール、ゴブリン等）はOK。
