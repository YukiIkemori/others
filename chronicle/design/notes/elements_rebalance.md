# 属性の見直し（2026-10-04）

持ち主・テスター「炎魔法強すぎて他を覚える必要性が感じられない。炎弱点のボス多すぎるし、強すぎる。炎無効とか吸収とか、色々なんとかならん？」への対応。

## 方針

1. 火の弱点をおよそ半分に。ほかの属性へ、魔物の性質（系統・種族・名前・地方）に合わせて配り直す（でたらめにしない）。
   - 夜行・地中の物（モグラ・サンドワーム）・暗がりのキノコ → 光。日なたの植物（サボテン）・鏡のカブト → 闇。
   - 骸骨（骨は燃えない）・小さな地べたの獣（ネズミ）・ゼリーと白銀ゼリー・氷の船の亡者 → 土。砂漠のヘビ → 水。
   - 飛ぶ物（ハチ・コウモリ）は風だけに。土の親和の物（甲虫・モグラ・サソリ）は輪のとおり風。
   - 火のまま残した物: 植物（花・木）・紙と本・ミイラ・クモ・雪男・氷の小僧（1〜3）・狼（森・雪）・マンモス。
     会話の手がかり（「紙の化け物なら火に弱い」「雪男は火に弱い」「根っこは火がきらい」「氷の巨人は火に弱い」）はそのまま当たる。
2. 火を受けつけない物を足す。火の地方の物（火トカゲ・火の悪魔・火炎の石像鬼・鬼火・炎の魔術師・火山ガメ）を無効か吸収に。
   砂漠のサソリ・坑道のゴーレム・雪の大将と冬将軍は火に耐える（0.75）。
   ボスは 炎の番犬（無効）・溶岩の巨獣（吸収、もとから）・術師の姉ヒノエ（無効）・日の玉（無効）。
   灰の荒野の全部を無効にはしない（大鬼・まだら獣・石像鬼・すす悪魔には火がまだ通る。打撃とほかの属性で詰まない）。
3. 火の術を少し下げる（火だけが段 2 で全体を打てる）。
   - 火の矢（s_fire_1）威力 1.4 → 1.3（水と同じ）
   - 火の粉（s_fire_2）MP 5 → 6、威力 1.0 → 0.9
   - 炎の波（s_fire_4）MP 9 → 10
   - 小さな太陽（s_fire_5）威力 3.4 → 3.2
4. 調べるの文に「無効：〇」の行を足した（5 言語。吸収の行はもとから）。図鑑は弱点の印を出さない決まりのまま。
