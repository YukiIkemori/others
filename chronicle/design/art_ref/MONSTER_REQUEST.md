# 【画像生成AI向け 完全指示書】ゲーム「ルミナス・クロニクル」魔物の戦闘グラフィック一式

> **使い方（依頼する人へ）**：この文書と主人公の設定資料の画像（`hero_sheet_owner.png`）を添付し、「この指示書のとおりに、シート1から作って」と送る。
> 1枚できるごとに「次」と送れば、次のシートに進む。作り直させたいときは「シート◯のマス◯を作り直して（理由）」と送る。

---

## 1. あなた（画像生成AI）への依頼

あなたは、2D RPG「ルミナス・クロニクル」のドット絵アーティストです。
このゲームの**魔物（敵）の戦闘用の絵**を、**シート1〜61の順に、1回に1シートずつ**描いてください。
添付した主人公の設定資料は、**絵柄・ドットの細かさ・色の塗り方・大きさの見本**です。魔物もこの資料と同じ品質・同じ絵柄で描きます。

- 1回の返答で出す画像は**1枚だけ**。複数のシートを1枚にまとめない。
- 各シートを出したら、そのシートの「**確認項目**」と2章の決まりを自分で1つずつ確かめる。守れていない項目があれば、次へ進む前にその場で描き直す。
- 画像のあとに、次の3行だけを書く（長い説明は不要）。
  1. シート番号と、描いた魔物の名前
  2. 確認項目の結果（全部OK／直した項目）
  3. 「次は シート◯（名前）です」
- 依頼者が「次」と送ったら、次のシートに進む。
- 依頼者から修正の指示があれば、そのシート（またはそのマス）を同じ条件で描き直す。
- 描き終えたシートの決まりは、以降のシートでもずっと守る。途中で絵柄・ドットの細かさ・大きさの基準を変えない。
- 「◯◯と同じ種族」と書いてある魔物は、前のシートの元の魔物を見直して、仲間に見えるように描く。

出来上がった画像は、ゲーム側の仕組みで次のように加工されます。なので、**描き方の決まり（2章）を守ることが最優先**です。
- ドットの格子に揃え、色を整える
- 背景を抜き、1マスずつ切り分ける
- 足元の位置を揃えて、戦闘画面の左側に並べる
- 動き（揺れ・呼吸・点滅・のけぞり・倒れる）を付ける
- 夜の光・影・エフェクトを重ねる
- 色を替えて、同じ系統の強い魔物や「金色の個体」を作る

## 2. 全シート共通の決まり（必ず守る）

### 2.1 魔物の絵とは
- **魔物1体につき、戦闘用の絵が1枚だけ**。歩き・攻撃などのコマは描かない（動きはゲーム側で付ける）。
- ポーズは**待機の構え**：相手（右）をにらんで、いつでも襲いかかれる姿勢。腕・翼・尾は体から少し離して、形が分かりやすいようにする。
- 口は閉じても開いてもよい。攻撃の途中の瞬間（振り下ろし・噛みつき・吐く息）は描かない。
- 同じ絵が図鑑にも出る。1体ずつ「どんな魔物か」がひと目で分かるように。

### 2.2 向き（いちばん大事）
- **すべての魔物は右を向く**。体は少しこちらに向けた**4分の3の斜め横**（右向き）。
  - 戦闘画面では、魔物が左側に並び、右側に立つ主人公たちを向くため。
  - 主人公の資料の戦闘ポーズは左向きなので、**魔物はその逆向き**になる。
- 顔・目・口・武器・はさみ・針・角の先は右を向く。
- 背中側しか見えない向き、真正面、真横すぎて片目しか見えない向きにしない（目が 2 つある魔物は、奥の目も少し見える）。

### 2.3 ドット
- **本物のドット絵**として描く。
- **1ドット＝画像上で正確に8×8ピクセルの正方形**。シート全体・全マスでドットの大きさを同じにする。**主人公の資料とも同じ**にする。
- 次のものは使わない。
  - ぼかし
  - アンチエイリアス（なめらかな縁）
  - グラデーション
  - ノイズ・紙の質感
  - 半透明（霊・霧・影の勇者も、透かさずに淡い色で塗りつぶす。透けはゲーム側で付ける）
- **輪郭は1ドットの暗い色の線**。純粋な黒（#000000）は使わない。黒に近い紫・茶と、その部分のいちばん暗い色を混ぜた色にする。内側の線は部品の境目だけに引く。
- 1体の色数は**32〜48色まで**（小さい魔物は32色以内）。1つの素材（毛・殻・布など）は**4〜6段**の陰影。
- **影は色相をずらす**：影は赤紫・青紫へ（例：緑の葉の影は赤紫、灰色の毛の影は青紫）、明るい所は黄色寄りへ。影ほど少し鮮やかにする。
- 全体は**落ち着いた彩度**。ボスは、目や核など**「視線の的」を1か所だけ**鮮やかにする（指示にある所）。
- 目は、白い点（1ドット）を入れて生き生きさせる。
- 細かい模様を増やすより、**大きな塊（明るい所・暗い所）**で形を見せる。

### 2.4 大きさ（ドットの数で決める）
主人公は戦闘で**身長64ドット**（画像上512px）です。魔物は主人公と**同じドットの細かさ**で、下の大きさにします（ゲーム側で拡大・縮小はしません。**ドットの数がそのまま画面の大きさ**になります）。

| 段 | 大きさ（体の**長いほうの辺**） | 画像上 | 例 |
|---|---|---|---|
| 主人公（見本） | 身長 64ドット | 512px | — |
| 小（S） | **36〜44ドット**（目安40） | 約320px | ゼリー・ネズミ・コウモリ・ハチ |
| 中（M） | **48〜56ドット**（目安54） | 約430px | カニ・オオカミ・人食い花・ミイラ |
| 大（L） | **80〜110ドット**（幅86・高さ112ドットの中） | 約640〜880px | 魔木・マンモス・大ダコ・ボスのお供 |
| ボス | 中ボス **120〜150ドット**、地方ボス・最後のボス **150〜180ドット**（シートごとに指定） | 約960〜1440px | — |
| 人の姿のボス | 身長 **68〜84ドット**（シートごとに指定） | 約540〜670px | ロウェル・ラザロ・勇者の影 |

- 横に長い魔物（カニ・オオカミ・ヘビ・マンモスなど）は**横幅**が、縦に長い魔物（人型・木・立ち上がるヘビ）は**高さ**が、この長さになる。
- 同じシートの魔物は、みな同じ段の大きさにそろえる。1体だけ極端に大きい・小さいのはだめ。
- 「同じ種族の上の段」（王・長老・大将など）は、元の魔物と同じ段の中で**少し大きめ**に描いてよい。

### 2.5 背景・配置
- 背景は**すべて単色のマゼンタ #FF00FF**。
- 床・地面・床の影・水面・砂・台・枠・飾り・文字・見出し・番号・名前・説明文は**描かない**。
- シートは**マス**に分ける（マスの線は描かない。見えない枠として使う）。
  - 小・中のシート：横長 **1536×1024px** を **横3 × 縦2 のマス**（1マス 512×512px ＝ 64×64ドット）。マスの番号は左上から右へ 1・2・3、下の行が 4・5・6。
  - 大のシート：横長 **1536×1024px** を **左右2マス**（1マス 768×1024px ＝ 96×128ドット）。左が1、右が2。
  - ボスのシート：シートごとに指定の **横長 1536×1024px** か **縦長 1024×1536px** に1体だけ。画像の端から6ドット（48px）以上あける。
- **1マスに1体**。マスの中央に置き、マスからはみ出さない。となりの魔物とは**8ドット（64px）以上**はなす。
- 地面に立つ魔物は、**足元（体のいちばん下）をマスの下の辺から6ドット（48px）上**にそろえる。飛ぶ魔物（指示に「飛ぶ」とある）は、マスの上下のまん中に浮かせる。
- **1体の絵はひとつながりにする**。離れて浮いた部品（王冠・しずく・粒・火の粉・星・紙片・泡）を作らない。しずくや紙片は体につなげるか、描かない。
- 空いているマスには何も描かない。

### 2.6 光とエフェクト
- 光は**正面の上からの、白い普通の光**だけ。
- このゲームは「太陽が消えた夜の世界」だが、**夜の暗さ・月光の青・灯りの橙はゲーム側で重ねる**。魔物は暗く塗らず、**普通の明るさ**で塗る。
- 次のものは**描かない**（ゲーム側で後から付ける）。
  - 光のにじみ・光の輪・後光の光（金属の輪などの「物」は描いてよい）
  - オーラ・もや・煙・湯気・吐く息・冷気
  - 魔法の光・炎のゆらぎ・火の粉・電気・キラキラ
  - 斬撃の軌跡・残像・動きの線
  - 縁の光（リムライト）・逆光
  - 床の影・水しぶき・舞う砂や雪
- 光る部分（鬼火の炎・炉の火・光る目・宝石）は、**明るい色の塊**として体の中に描く。周りを明るくしない。
- 炎の体（鬼火・たてがみの炎など）は、はっきりした色の段で描いた**固い形**にする。

### 2.7 描かないもの（ゲーム側で作る）
- **金色の個体**（どの魔物にもある、まれに出る金色の色違い）。
- 指示書にない**上の段の魔物**（例：あわゼリー・毒ゼリー）。これらはゲーム側で、描いた絵の色を替え、小物（兜・王冠・眼帯など）を足して作る。
- ボスの別の姿の色違い（例：冷えた溶岩の巨獣）。

### 2.8 出力
- **PNG**で出力する。JPG にしない。
- 画像の大きさは、シートの指定どおり **1536×1024px（横長）** か **1024×1536px（縦長）**。
- 1回の返答で1枚だけ。

### 2.9 世界と絵の方向
- 世界：**太陽が昇らなくなった、長い夜の世界**。人々はランプとかがり火と「大灯火（おおともしび）」の明かりの中で暮らし、灯りの外の闇に魔物がすむ。
- 魔物の絵：くっきりした**上質なドット絵**。等身の小さいデフォルメではなく、**少し重みのある、しっかりした生き物**として描く（主人公の資料と同じ世界の住人に見えること）。かわいい魔物（ゼリー・妖精・レア）は愛嬌を、ボスは迫力を。
- 「白紙」「紙」「文字」の出てくる魔物は、**伝承が忘れられて生まれた魔物**（物語の敵）。白い紙・消えかけた文字・ぎざぎざの切り口が共通の目じるし。
- 実在の作品のキャラクター・魔物・意匠をまねしない。

## 5. よくある失敗と直し方（あなた自身で確かめて直す）

| 失敗 | 直し方 |
|---|---|
| 魔物が左や正面を向いている | 全部右向き（4分の3の斜め横）にして描き直す |
| ドットがぼやける・縁がなめらか・グラデーション | アンチエイリアスとぼかしをなくし、1ドット＝8×8pxの正方形・段の色で描き直す |
| 大きさがシートの段と合わない・マスによって大きさがばらばら | 2.4 の表の長さにそろえる。同じシートは同じ段の大きさ |
| 光・オーラ・炎のゆらぎ・煙・キラキラを描いてしまう | 普通の光だけにし、エフェクトは消す。光る所は明るい色の塊だけ |
| 床の影・地面・水・台を描いてしまう | 消して、マゼンタの背景だけにする |
| 文字・番号・名前・枠を描いてしまう | 全部消す |
| 部品や粒が体から離れて浮いている | 体につなげるか、消す |
| 霊・霧・影を半透明に描く | 透かさずに淡い色で塗りつぶす |

| 暗い夜の色で塗ってしまう | 普通の明るさで塗り直す（夜の色はゲーム側） |

## 6. 依頼する人への補足（画像生成AIは読まなくてよい）

- できた画像は **PNG のまま**、シート番号の名前にして Claude に渡す。
  - 名前：**`mon_s01.png` 〜 `mon_s61.png`**（番号は2けた。例：シート12 → `mon_s12.png`）
  - 作り直した物は `mon_s12_v2.png` のように後ろに付ける（いちばん新しい物を使う）。
  - マス1つだけ作り直した場合も、そのシート全体の画像を渡す。
- 次のような小さなずれは、ゲーム側の仕上げで直せるので作り直さなくてよい。
  - ドットの細かなにじみ・ドットの大きさが8pxより小さい
  - 数ドット〜1割くらいの大きさの誤差
  - 背景の色むら・マスの位置の小さなずれ
- 次のどれかがあれば、**作り直しを頼む**。
  - **向きが違う**（右を向いていない）
  - **説明と違う魔物**になっている（別の生き物、決め手の特徴が無い、色がまったく違う）
  - **段の大きさと大きく違う**（小のシートなのに大きい、ボスが小さい、同じシートでばらばら）

## 付録B 大きさの決め方（Claude 向けの制作メモ）

- 主人公の戦闘の身長を **64ドット**（ARUN_REQUEST.md のシート5〜8）とし、魔物も同じドットの細かさで描く（STYLE_REFERENCE §4.1「魔物の画素の大きさは人物と同じ」）。
- 画像AIの出せる画像は最大 1536px。1ドット＝8px では **1辺192ドット**が上限なので、ボスの上限を **180ドット**（主人公の約2.8倍）にした。STYLE_REFERENCE のボス 3.5〜4倍（224〜256ドット）はこの方法では描けない。
- 小・中は 6体を1枚（1マス64ドット）に入れるため、**小 36〜44・中 48〜56ドット**（主人公の0.6〜0.9倍）。STYLE_REFERENCE の「雑魚は人物の1.5〜2.3倍」（v2 の `R.Beast.tierPx` は人物70で S 51〜70・M 70〜105）より小さい。**リードの判断が要る**：このまま小さめで使うか、小・中も大と同じ「1枚2体（1マス 96×128ドット）」にして大きくするか（シート数は約2倍の約110枚）。
- 大（L）は 80〜110ドット（主人公の1.25〜1.7倍）、中ボス 120〜150（約2〜2.3倍）、地方ボス・最後 150〜180（約2.3〜2.8倍）。人の姿のボス（ロウェル・ラザロ・勇者の影）は人の大きさ（68〜84ドット）。
