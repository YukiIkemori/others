# 【画像生成AI向け 完全指示書】ゲーム「ルミナス・クロニクル」主人公アルンのドット絵素材一式

> **使い方（依頼する人へ）**：この文書と設定資料の画像（`hero_sheet_owner.png`）を添付し、「この指示書のとおりに、シート1から作って」と送る。
> 1枚できるごとに「次」と送れば、次のシートに進む。作り直させたいときは「シート◯を作り直して（理由）」と送る。

---

## 1. あなた（画像生成AI）への依頼

あなたは、2D RPG「ルミナス・クロニクル」のドット絵アーティストです。
添付した設定資料の主人公**アルン**について、ゲームで使うドット絵素材を**シート1〜9の順に、1回に1シートずつ**描いてください。

- 1回の返答で出す画像は**1枚だけ**。複数のシートを1枚にまとめない。
- 各シートを出したら、そのシートの「**確認項目**」を自分で1つずつ確かめる。守れていない項目があれば、次へ進む前にその場で描き直す。
- 画像のあとに、次の3行だけを書く（長い説明は不要）。
  1. シート番号と名前
  2. 確認項目の結果（全部OK／直した項目）
  3. 「次は シート◯（名前）です」
- 依頼者が「次」と送ったら、次のシートに進む。
- 依頼者から修正の指示があれば、そのシートを同じ条件で描き直す。
- 描き終えたシートの決まりは、以降のシートでもずっと守る。途中で絵柄・大きさ・色を変えない。

出来上がった画像は、ゲーム側の仕組みで次のように加工されます。なので、**描き方の決まり（2章）を守ることが最優先**です。
- ドットの格子に揃える
- 背景を抜く
- 大きさと足元を揃える
- 動きをつなげる

## 2. 全シート共通の決まり（必ず守る）

### 2.1 キャラクター
- 添付の設定資料と**同じ人物・同じ服・同じ配色**。
  - 灰茶色のくせ毛
  - 赤いマフラー
  - 黒い上着と生成りの布
  - 茶色の革の胸当て・ベルト・小物入れ
  - 茶色のブーツ
  - 片手剣（資料と同じ形）
- 顔立ちは資料どおり。若い剣士で、芯の強さと優しさがある。
- 等身は**約2.7頭身**。頭が大きく首が細く、裾が広がるシルエットにする。
- 配色は資料の「配色」欄に合わせる。
  - 影は赤紫寄り、明るい所は黄寄りにずらす。
  - 顔の周りをいちばん明るくする。

### 2.2 ドット
- **本物のドット絵**として描く。
- **1ドット＝画像上で正確に8×8ピクセルの正方形**。シート全体・全ポーズでドットの大きさを同じにする。
- 次のものは使わない。
  - ぼかし
  - アンチエイリアス（なめらかな縁）
  - グラデーション
  - ノイズ・紙の質感
  - 半透明
- 輪郭は1ドットの暗い線。純粋な黒ではなく、黒に近い色と、その部分の一番暗い色を混ぜる。内側の線は部品の境目だけに引く。
- 1キャラの色数は**50色前後まで**。肌は3〜4段、服の主な色は6段くらいの陰影にする。
- 目は2×2〜3ドット。まつげの暗い列・瞳の色・1ドットの白いハイライトで描く。口は基本的に描かない（表情シートは除く）。

### 2.3 背景・配置
- 背景は**すべて単色のマゼンタ #FF00FF**。
- 床の影・地面・枠・飾り・文字・見出し・番号・説明文は**描かない**。
- ポーズは**格子状に等間隔**で並べる。ポーズどうしの間は、最低でも10ドット（80px）以上あける。
- 同じシートのポーズは**身長を同じ**にする。**足の裏の線（接地線）は行ごとに同じ高さ**にする。
- キャラの一部（剣先・マフラー）が隣のポーズや画像の端にかからない。

### 2.4 光とエフェクト
- 光は**正面の上からの普通の光**だけ。
- 次のものは描かない。ゲーム側で後から付ける。
  - 夜の灯り
  - 逆光
  - 光の筋
  - キラキラ
  - 炎のゆらぎ
  - 斬撃の軌跡
  - 魔法の光
  - 残像

### 2.5 出力
- **PNG**で出力する。JPG にしない。
- 画像の比率は、横長16:9か正方形。ポーズが全部はっきり入る大きさにする。

## 3. 描いてほしいシート

**★は必須**、☆はあると良いもの。**★を先に全部**描き、そのあと☆を描く。
描く順番：1 → 2 → 3 → 5 → 6 → 7 → 9（★）→ 4 → 8（☆）

### フィールド用（真上寄りの見下ろし、町やダンジョンを歩く絵）
- 身長：**頭から足まで48ドット**（画像上384px）
- 角度：少し上から見下ろした、正面寄りの斜め見下ろし
- 向き：下（手前）・上（奥）・左・右

#### シート1 ★ 歩き（ランタンを持つ）
先頭を歩くキャラは夜の世界を照らすランタンをいつも持っている。**左手に小さなランタン**（真鍮の枠、ガラスの中に炎。光のエフェクトは描かない）、**剣は腰の鞘**に収める。

- 並べ方：4行×3列
  - 行1：下向き（手前へ歩く）→ 立ち／右足前／左足前
  - 行2：上向き（奥へ歩く、背中側）→ 立ち／右足前／左足前
  - 行3：左向き（真横）→ 立ち／前の足を出す／後ろの足を出す
  - 行4：右向き（真横）→ 立ち／前の足を出す／後ろの足を出す
- 「立ち→右足→立ち→左足」とつなげると歩いて見えるようにする。
- マフラーの端を歩きに合わせて少し揺らす。

**確認項目**
- [ ] 4方向とも同じ人物に見える。上向きでは後頭部とマフラーの結び目が見える
- [ ] 12コマすべてランタンが左手にある（右向きでは体の奥側で、少し隠れてよい）
- [ ] 12コマすべて身長48ドット、行ごとに足の裏の高さが揃っている
- [ ] 背景はマゼンタ単色で、影・文字・枠がない

#### シート2 ★ 走り
シート1と同じ大きさ・同じ装備（左手にランタン、腰に鞘の剣）。

- 並べ方：4行×4列（下・上・左・右の4方向 × 走り4コマ）
- コマの順：右足で着地／両足が浮く／左足で着地／両足が浮く
- 上体を少し前に傾け、マフラーを後ろになびかせる。

**確認項目**
- [ ] 4コマをつなげると走って見える
- [ ] 身長と足元の高さが揃っている（浮くコマは足元が少し上がってよい）

#### シート3 ★ 演技ポーズ（会話・イベント用）
シート1と同じ大きさ。**向きはすべて下向き（手前）**。**ランタンは持たない**。剣は腰の鞘。

- 並べ方：3行×4列、次の12ポーズ
  1. うなずく
  2. 驚く（少しのけぞる）
  3. 首をかしげる（考える）
  4. お辞儀
  5. 片ひざをつく
  6. 地面に座る
  7. 手を挙げて呼びかける
  8. 横を向いてあたりを見回す
  9. 倒れて横たわる
  10. 剣を抜いて構える
  11. 胸に手を当てる（決意）
  12. うつむく（落ち込む）

**確認項目**
- [ ] 12ポーズとも同じ人物・同じ大きさ（しゃがむ・座る・横たわるは、立ったときと同じ縮尺）
- [ ] 足元（または地面に触れている所）の高さが行ごとに揃っている

#### シート4 ☆ 演技ポーズ（上向き・横向き）
シート3の「うなずく／驚く／手を挙げる／剣を構える」を、**上向き**（行1）と**左向き**（行2）で描く。並べ方は2行×4列。

### 戦闘用（横から見た戦闘画面）
- 身長：**頭から足まで64ドット**（画像上512px）
- 向き：**すべて左向き**。体は少しこちらに向けた4分の3の斜め横にする。
  - 戦闘画面では味方が右側に立ち、左側の敵を向くため。
- ランタンは持たない。右手に片手剣。

#### シート5 ★ 戦闘の基本ポーズ
- 並べ方：2行×5列、次の10ポーズ
  1. 待機A
  2. 待機B（呼吸で肩と剣先がほんの少し下がる。待機Aとの差は2〜3ドットだけ）
  3. 一歩前に踏み出す
  4. 防御（剣を横に構えて身を固める）
  5. ダメージ（のけぞる）
  6. 瀕死（片ひざをつき、剣を地面に立てて支えにする）
  7. 戦闘不能（倒れて横たわる）
  8. 勝利A（剣を高く掲げる）
  9. 勝利B（剣を下ろし、振り返って微笑む）
  10. 閃き（はっと顔を上げる）

**確認項目**
- [ ] 10ポーズすべて左向き（右を向いているものがあれば描き直す）
- [ ] 待機AとBを交互に見ると呼吸しているように見える（差が大きすぎない）
- [ ] 身長64ドット、行ごとに足元の高さが揃っている

#### シート6 ★ 戦闘の行動ポーズ
シート5と同じ大きさ・向き・装備。

- 並べ方：2行×5列、次の10ポーズ
  1. 斬る前の振りかぶり
  2. 斬った直後の振り抜き（剣を振り下ろしきった形）
  3. 突きの構え
  4. 突き（腕を前に伸ばしきる）
  5. 大技のため（剣を後ろに引き、身を低く沈める）
  6. 大技の一撃（跳び上がって振り下ろす途中）
  7. 術の詠唱A（片手を前にかざす）
  8. 術の詠唱B（片手を高く掲げる）
  9. 道具を使う（小瓶を掲げる）
  10. 身をかわす（後ろへ跳ぶ）
- 斬撃の軌跡・光・残像は描かない。

**確認項目**
- [ ] 1→2と並べると斬ったように、3→4と並べると突いたように見える
- [ ] 全ポーズ左向き・同じ大きさ

#### シート7 ★ 武器を持たない版と、武器だけ
仲間が別の武器に持ち替えたときに使うためのシート。

- 行1：シート5・6の「待機A／振りかぶり／振り抜き／突き／詠唱A」の5ポーズを、**武器を持たずに**描く。手は武器を握る形のままにする。大きさ・向き・位置はシート5・6とまったく同じ。
- 行2：**武器だけ**を、刃先や先端を左に向けて横向きに5つ並べる。
  - 片手剣（アルンの剣）
  - 大剣（両手で持つ幅広の剣）
  - 短剣
  - 弓（弦を張った短い弓）
  - 杖（先に宝石）
- 武器のドットの大きさはキャラと同じにする。

**確認項目**
- [ ] 行1の手の位置に武器を重ねたとき、自然に握って見える
- [ ] 武器5つがキャラと同じ縮尺

#### シート8 ☆ 戦闘の追加ポーズ
シート5と同じ条件で、1行×4列。
1. 逃げる（背を向けて走る。右向きでよい）
2. 眠り（頭が下がる）
3. 混乱（よろめく）
4. 仲間をかばう（前に出て腕を広げる）

### 顔（会話・メニュー用）

#### シート9 ★ 顔の表情
- 大きさ：胸から上のバストアップ。**幅約80ドット×高さ約80ドット**（画像上640×640px）。
- 向き：**少し右向き**（画面の左端に置いて、右にいる相手と話す）。
- 並べ方：2行×4列、次の8つの表情
  - 通常
  - 真剣
  - 微笑み
  - 笑う
  - 驚き
  - 悲しみ
  - 怒り
  - 疲れ（汗）
- 表情以外（髪・マフラー・服・向き・大きさ・位置）は8枚とも完全に同じにする。

**確認項目**
- [ ] 8枚を重ねたとき、顔の表情以外はずれない
- [ ] 設定資料の顔と同じ人物に見える

## 5. よくある失敗と直し方（あなた自身で確かめて直す）

| 失敗 | 直し方 |
|---|---|
| ドットがぼやける・縁がなめらか | アンチエイリアスとぼかしをなくし、1ドット＝8×8pxの正方形で描き直す |
| ポーズごとに大きさが違う | 身長をそのシートの指定（48／64ドット）に揃え、足元の線を揃える |
| 向きが違う | 戦闘は全部左向き。フィールドは行ごとの指定どおりにする |
| 背景に影・模様・文字・枠が入る | 背景はマゼンタ #FF00FF の単色だけにする |
| 顔・髪型・マフラー・服の色が資料とずれる | 設定資料に戻して描き直す。人物が違って見えるのは一番の失敗 |
| 光やエフェクトを描いてしまう | 普通の光だけにし、エフェクトは消す |
| ポーズどうしがくっつく・画像の端で切れる | 間隔を80px以上あけ、全部が画像に入るよう並べ直す |

## 6. 依頼する人への補足（画像生成AIは読まなくてよい）

- できた画像は **PNG のまま** Claude（ゲームの制作）に渡す。
- 次のような小さなずれは、ゲーム側の仕上げで直せるので作り直さなくてよい。
  - ドットの細かなにじみ
  - 数ドットの大きさの誤差
  - 背景の色むら
- 次の2つだけは、作り直しを頼む。
  - **人物が違って見える**
  - **向きが違う**
- 作り直しの頼み方の例：「シート5の7番が右を向いている。全部左向きにして、同じ条件で描き直して」
