- 足もとに大きく柔らかい影。ボスの影は横に長い（体の幅の 1.3 倍）。

### 5.3 灯り（光源）の描き方

- **3 点セット**: ①小さな芯（ほぼ白〜淡い黄、2〜4 画素）、②芯の **約 3 倍の半径**の柔らかいにじみ（加算、中心の不透明度 .5〜.7 から 0 へ）、③地面の**光だまり**（半径は**人の背の 1.5〜2 倍**、中心 +40〜60% の明るさ、外へ滑らかに）。
- 光だまりの中では物の色が**暖色に寄り**（人物・石畳が橙がかる）、外は青紫のまま。**同じ人物が灯りの側だけ暖かい**（片側のリム）。
- 窓明かり: 窓の格子（2×2、2×3 の小さな枠）の中を**暖色でべったり**塗り、枠は暗い。窓の下の地面に弱い光だまり。**開いた戸口は画面で一番明るい長方形**（人の目が行く「入れる所」の合図）。
- 篝火・松明: 炎の形は 2〜3 コマのゆらぎ、上に火の粉の粒 3〜8。光だまりの半径は街灯の 1.3 倍、明るさが少し揺れる（±8%、2〜4 Hz）。
- 張り渡した灯り（紐に吊るした小さな灯りの列）: 手前の物は大きくぼけて丸い光になる。我々は見下ろしなので、**紐の影と小さな光の点の列**として描ける。

### 5.4 光の筋・もや・粒

- 光の筋: 斜め（上から 20〜35°）の細長い帯を**加算で 10〜25%**。夜は月の青、屋内・洞窟は天井の穴からの青白い光。筋の中を粒がゆっくり漂う。
- もや: 画面の奥（上）ほど濃い、色は暗部の色より少し明るい青紫。
- 粒: 夜の森・戦闘に**20〜40 個**の暖色の小さな光（2〜4 画素、一部はぼけて大きい）。雪・落ち葉・火の粉・蛍・胞子など場面ごとに 1 種類。ゆっくり（1 秒に数画素）、明滅（周期 2〜4 秒）。
- ART_REWORK §1.5.1 の L2（光の筋）・L7（粒）・L8（減光＋色調）とそのまま対応する。量の目安を上の値で持つ。

### 5.5 天気

- 雪: 画面全体の青（195〜255°）の色調＋粒の雪（大小 2 種、手前の大きい粒は少し速い）＋地面の白の積もり。明るさの平均は夜の町より高い（.26）。
- 雨・霧: 霧は奥ほど濃い層を重ねる。雨は細い斜めの線（加算 10〜15%）。
- 我々の既存の天気の重ね（霧・砂嵐）は、**色だけ上の夜の色調に合わせる**（ART_REWORK §1.7-6 のとおり）。

### 5.6 夜に人物を読ませる工夫

- 人物は場面の色調で青く沈むが、**リム（光源側の縁の 1 画素の明るい線）**と、明るい髪・白い布で読ませる（夜の町の写真で、銀髪の人物は画面の中で最も明るい物の一つ）。
- 足もとの影は夜でも残す（ただし短く、淡く）。
- 我々への言い換え: 夜の LUT を掛けたあとも、**人物の外周の縁と背景の明るさの差が .08 以上**あること（検査 §9）。足りなければ、リムの強さを上げるか、人物の LUT を背景より 10〜15% 明るくする（「人物だけ少し持ち上げる」）。

## 8. する / しない

### する
- 人物は 2.6〜2.8 頭身、頭と裾が同じくらい広く、首がくびれる 3 段の輪郭。
- 1 人を 6〜8 の塊で作り、塊の境にだけ暗い線。塊の中は段（3〜6）で陰を付ける。
- 影は赤・紫へ、明るい所は黄へ色相をずらす。影ほど彩度を上げる。
- 一番明るい画素は顔（と光る持ち物）。
- 目は 2 つ・白い点 1 画素。表情は体と目の形で。
- 看板の色 1 つ＋頭の形 1 つで 4 人を見分けさせる。主色の色相を 45° 以上離す。
- 魔物は人物と同じ画素の大きさで、人物より大きく。ボスは人物の 3〜4 倍。
- 夜は「濃い藍・紫」で塗り、真っ黒にしない。明るい所は画面の 1〜7%。
- 灯りは芯＋にじみ＋光だまりの 3 点セット。窓は暖色でべったり、開いた戸口は一番明るく。
- 周辺減光を強く（夜の四隅は中央の 3 割前後）。
- 通れる道・入口・宝箱・階段に光を当てる。
- 町は小物を固めて置き、通りは空ける。看板は絵で。
- 灯りを持つ先頭の人のまわりを暖色の光の輪にする。
- UI は薄く: 枠なし・細い線・半透明・選択行だけ明るく。

### しない
- 2 作の人物・魔物・意匠・ロゴ・UI の配置・アイコン・書体を写す。画像から色を拾う（スポイト）・形をなぞる。
- 斜めのカメラ・奥行きのジオラマ・被写界深度（手前のぼけ）をフィールドに入れる（戦闘の背景の手前のぼけは ART_REWORK L6 の範囲で可）。
- 夜の画面を黒 `#000` や彩度 0 の灰で塗る。全体を一様に暗くするだけの「夜」。
- 光る物を増やしすぎる（明るい画素が 10% を超える、1 人に光る物 2 つ以上）。
- 人物に細かいノイズの模様を敷き詰める（36 art px のフィールドの人物で特に）。
- 人物より小さい魔物ばかり並べる。ボスを人物の 2 倍以下にする。
- 魔物を色替えだけで段を分ける（ART_REWORK §2.5 のとおり）。
- UI に重い不透明の板・太い枠・影の強い立体のボタンを使う。

## 9. 絵の担当が確かめる一覧（チェックリスト）

数値は `tools/` の検査（ART_REWORK §7.5）に足せる形で書いた。道具が無いものは目で見て確かめ、報告に書く。

**人物**
- [ ] 戦闘の人物の全高 56〜62 art px、フィールドの人物 34〜40 art px（`ひろい`）。頭（髪の上端〜顎）/ 全高 = 0.35〜0.39。
- [ ] 行ごとの幅で、首の行が頭の最大幅の 50〜65% にくびれている。
- [ ] 1 コマの色数 40〜80（戦闘）、25〜55（フィールド）。1 素材の段数 ≤ 6（主役の服）、他 ≤ 5。
- [ ] 肌の段の色相: 最暗段が最明段より 5〜15° 赤寄り、最暗段の彩度が最明段より 0.2 以上高い。

- [ ] 画像の一番明るい画素（UI を除く）が肌か光る持ち物にある。
- [ ] 目が 2 つ見え、各目に 1 art px の明るい点がある（待機・歩き・勝利）。

- [ ] 足の間に 1 art px 以上のすき間（待機の正面・斜め）。足もとに柔らかい楕円の影。

**魔物・ボス**
- [ ] 魔物の画素の大きさが人物と同じ（拡大していない）。
- [ ] 地方ボスの高さが人物の 3 倍以上（案。リードの決定待ち §10）。
- [ ] 影側の色相のずらし −30° 以上。夜の LUT の後も輪郭が背景から読める。
- [ ] ボスに視線の的（目・核）が 1 つ、そこだけ彩度 ≥ 0.8。

**夜の画面（フィールド・戦闘の night・夜の町）** — 320×180 に縮めて測る
- [ ] 平均輝度 0.14〜0.22、5% 分位 0.02〜0.05、95% 分位 0.35〜0.60。
- [ ] 輝度 > 0.75 の画素が 1〜7%。

- [ ] 窓は暖色で埋まり、開いた戸口が画面で最も明るい面の一つ。

## 10. リードに決めてほしいこと（この分析から出た案）

| # | 案 | 理由 |
|---|---|---|
| R1 | 地方ボスの高さを 70〜100 → **90〜120 論理 px**（人物の 3〜4 倍）。 | 2 作のボスは人物の 3.5〜4 倍で、画面の半分を占める。 |
| R2 | S・M の雑魚を少し大きく（S 22〜30、M 30〜45）。 | 2 作の雑魚は人物の 1.5 倍以上。人物より小さい敵が多いと画面が寂しい。 |
| R3 | 素材の段の上限を「主役の服だけ 6」に。 | 2 作の主色の服は 6〜8 段。 |
| R4 | **先頭の人物の灯りの輪**をフィールドの基本の表現にする（遊びの仕掛けと結ぶかは別に決める）。 | 主題（灯りで生きる夜の世界）を 1 目で見せる。 |
| R5 | 夜の色調の目標値（§5.2）を `R.Hd.mood` の `night` と、夜の町の `map.light` の調整の基準にする。 | 数値で合わせられる。 |
| R6 | フィールドの人物・NPC に演技のコマ 8〜12 種を足す（§2.6）。 | 物語の場面は顔の絵でなく体の演技で見せる作り。 |
