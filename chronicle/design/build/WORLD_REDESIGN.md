### 2.6 景色の目印（ランドマーク）
世界地図に「遠くから見える目印」を置き、寄り道へ誘う。どれも専用のワールドタイル（2×2〜3×3の飾り）で、近づくと看板か出来事がある。

- 山地：鍛冶神の大きな石像（山腹に彫られた顔）、坑道の櫓。
- 高原：星読みの塔、列柱の輪（石舞台）、星降りの窪地。
- 湿原：鐘楼の見える沼、霧の館の尖塔、沈んだ礼拝堂の屋根。

### 2.7 寄り道の場所（36か所）
「T」は目安のティア（行けるようになる時期と、敵の強さの目安）。敵の強さは原則ティア連動（`'dyn'`）で、ダンジョンの `lvOff` を +1〜+2 にする。
**「固定」と書いたもの（隠しボスなど）だけは強さが固定**で、手前の看板と噂で「危険」と知らせる。報酬の「一品物」は新規の固有品（§7.4 の `u_*`、約24点）。

| # | 名前 | 種類 | 場所・行き方 | T | ひとことの誘い | 報酬 |

## 3. 情報の出し方（「次はこれ」をやめる）

### 3.1 原則
1. **向こうから寄ってきて事件を話すNPCを置かない**（今の `<町>_intro` の onEnter は、町の空気を見せる演出だけに変える。例：広場に人だかり、鐘が鳴らない、門が閉まっている）。
2. 情報は **自分で聞きに行く**：酒場の噂、掲示板、町の人、手紙、書き付け、年代記。どれも「かもしれない」「らしい」の言い方で、正解を1本だけ示さない。
3. 聞いた情報は **手がかり帳** に自動でたまる。どれを追うかはプレイヤーが決める。
4. 「次の目的地の表示」（標準仕様）は残す。ただし **手がかり帳で自分が目印を付けた手がかり** を表示する。何も目印を付けていなければ「手がかり帳を開いて、行き先を決めよう」とだけ出す。
5. 1つの地方の中でも、手がかりは **2〜3本が同時に開いている** ようにする（順番のある一本道にしない）。

### 3.2 手がかり帳（新しい仕組み）
**データ** `src/data/leads.js`（新規）
```
R.DB.leads[id] = {
  title: '木こりたちが帰らない',           // 一覧の見出し（全角14字以内）
  text: 'フェルンの樵が三人、森から\n戻らないらしい。',   // 詳しい文（2〜3行）
  region: 'r_forest' | null,               // 地方の見出しでまとめる。null は「世界のうわさ」
  from: 'ファロスの酒場',                    // どこで聞いたか（一覧に小さく出す）
  place: 'fern' | {x,y,map} | null,        // 目印を付けたとき、地図に出す場所（分からない手がかりは null＝方角だけ）
  dir: '西',                                // place が null のときに出す方角
  done: 'cleared_r_forest' | cond,         // 解決の条件（R.State.check）
  hideWhen: cond,                           // これが真になったら一覧から消す（古くなった話）
  kind: 'main' | 'region' | 'side' | 'rumor' | 'map',
}
```
**状態**（`R.Game.leads[id] = {got:時刻, pin:bool, seen:bool}`）と API（`R.Leads`、`src/systems/leads.js` 新規）
```
R.Leads.add(id)       // 聞いた。すでにあれば何もしない。小さく「手がかり帳に書いた」と表示（効果音）
R.Leads.pin(id)       // 目印を付ける（1つだけ）。目的の表示と地図の印がこれに変わる
R.Leads.list()        // [{id, state:'new'|'open'|'done'}]、地方ごとにまとめる
ev.lead(id)           // イベントから呼ぶ（= R.Leads.add）
```
**画面**：メニューの「年代記」に「手がかり」のページを足す（A11 のコンパクト表示。新しい窓を増やさない）。
- 左：地方の見出し（行ったことのない地方は「西のうわさ」のように方角で）。右：その地方の手がかり（新しいものに印）。
- A で詳しい文、もう一度 A で「目印を付ける」。解決したものは文字が薄くなり、年代記の章へつながる。
- 目印を付けた手がかりに `place` があれば、フィールドの目的の行とメニューの地図に印（点滅する小さな羽ペン）。
- 今の目的（`obj_*`）の仕組みは、**手がかりの文を出す器として残す**（`R.Game.objective` に目印の手がかりの title を入れる）。

**どこまで教えるか**
- 手がかりは「場所」までで、「何をすればよいか」の手順は書かない。手順は町の人と現場で分かる。
- 地方の中の手がかりは3種類：事件そのもの（`region`）、事件の裏の手がかり（`region` の2本目以降）、小さな依頼（`side`）。
- 本筋の手がかり（`main`）は、ティアの場面と手紙でだけ増える（§3.4）。

- **ティアの場面 T1〜T8**：中身とボイスは今のまま。出し方だけ変える。

- **本筋の謎の手がかりの散らし方**：今は「記録院の人が来て写していった」が8地方すべて同じ。案では **地方ごとに違う形の証拠** にする（§4 の各地方の「本筋とのつながり」）：

  誓いの碑の拓本の受け取り書（鉱山）、大会の名簿の「記録院付き」の闘士（灰）、学院への封鎖の命令書とラザロの署名（星）。
  8つを集めると「記録院が各地の伝承を集めている理由」が見えてくる（手がかり帳の「世界のうわさ」に並ぶ）。
- **寄り道で深まる謎**：語り部の墓の小島（#28）、隠れ里ユラ（#4）、東の果ての岬（#31）で、フィーネの正体と白の書の由来を先に知ることができる（知らなくても終盤は同じ。知っていると T8 と終盤の台詞が一部変わる：`cond` で2〜3行）。
- **序章の旅立ち（P10）**：ベルナが8地方の噂を一気に読み上げるのをやめる。ボイスの5行（v_berna_lute_01〜05）はそのまま。
  そのあとに「噂は酒場に集まるものさ。まずは港の酒場で聞いてごらん。」（ボイスなし）と手がかり帳を渡す。ファロスの酒場で最初の噂が聞ける。
- **終盤**：今のまま（8枚のページ → ロア → ファロスの港からビブリアへ）。外洋船を持っていれば自分の船でもビブリアへ渡れる（霧が晴れたあと）。

### 3.5 ティアと自由順を崩さない決まり
1. 地方の話の中の戦い（大会、籠城、護衛の戦い）は **すべて `scale:'tier'`**。レベルは `LZ(T) + lvOff` のまま。
2. 選択で変わる報酬は、**ティア宝箱（プール）か、どちらを選んでも同じ強さの一品物** にする。片方だけが強い、にしない。
3. 地方の解決にかかる時間の目安をそろえる（2.5〜3.5時間）。長い地方ほど途中の回復の泉と宿場を増やす。
4. 寄り道の一品物は、**行けるようになる時期のティアで強さを決める**（小舟で行ける所はT1〜2相当、外洋はT5相当、空路はT6相当）。固定の強さの隠しボスは、手前の看板と噂で「危険」と分かるようにする。
5. どの地方も、ほかの地方の解決を前提にしない（小舟・外洋船・火の鳥は寄り道を広げるだけで、地方の話には要らない）。
6. 1つの地方の途中で別の地方へ行ってもよい。地方の途中の状態（どこまで調べたか）は地方ごとのフラグで持つ。
7. 地方を解決していなくても、ティアが上がれば敵は強くなる（今と同じ）。地方の中の依頼は、解決の前後どちらでも受けられるものを多くする。

### 4.1 森（フェルン）「迷子さがし」— 章題「千年樹の歌」
**前提**：樵が3人、森から戻らない。樵頭ゴードの息子ピム（10歳）が、父を探しに一人で森に入ってしまった。森は歌を忘れて道を変え、人を迷わせている。

**町に入ると**：広場で捜索隊が出発の相談をしているが、森が道を変えるので誰も奥へ行けない。話しかけてこない。掲示板に「捜索隊、求む。――樵頭ゴード」。

**手がかり（同時に開くもの）**
- 「ピムを探して」（母マルタ。家でピムの帽子の片方を渡してくれる。帽子があると、森の中でピムの足あとが光って見える）
- 「樵の三人」（ゴード。3人の持ち物：斧・弁当箱・笛。落ちている持ち物から足あとをたどる）
- 「森の歌」（木の上の家の歌い手リタ。昔の歌の石が3つ森にある。歌をそろえると森が道を変えなくなる）

**流れ**
1. 迷いの森（屋外の広いダンジョン、2階）。森の広場が小道でつながり、**歌の石を見つけるまでは広場の出口が入れ替わる**（今のキノコの輪の仕掛けを発展）。
2. 探す相手は4人、順番は自由。足あと（地面の印）を追う。見つけると一人ずつ村に戻る（「村へ帰れ」の短い演出。追従はしない）。
   - 樵ハンス：倒木の下（斧で開く通り道の先）。
   - 樵ベン：狼の群れに囲まれている（戦闘。勝つと救出）。
   - 樵ロイ：木のうろに隠れている。笛の音を聞いたら出てくる（笛は樵ベンが持っている）。
   - ピム：傷ついた森の獣（花角の小鹿）をかばって動けない。
3. **ピムの選択**：「ピムを村へ送り届ける」か「ピムを連れて進む」か。
   - 送る → 母マルタが礼に弁当（回復の品）と、ピムが見つけた「秘密のうろ」の話（隠し通路の手がかり）。
   - 連れて進む → ピムが一行の後ろについてくる（追従NPC）。狭い穴に入って向こうのスイッチを押してくれる（2か所で近道が開く）。敵には狙われない。千年樹の前で帰る。
4. **小鹿の選択**：「手当てする」（回復の品を1つ使う）か「そっとしておく」か。手当てすると、森の広場の抜け道を小鹿が案内してくれる（千年樹への近道）。解決後、村の外で小鹿に会える（レア魔物の巣の目印）。
5. 歌の石3つ → 森が止まる → 千年樹（中、2階）。根の奥で根食らい。倒すとエルムが目覚める（ボイス v_elm_forest_01〜06）。
6. 締め：村の広場で、帰った4人と村人が歌う。ピムが歌の一番をまちがえて笑いが起きる（ピムを連れて進んだときだけ、ピムが「ぼくも行ったんだ」と自慢する）。

**選択と結果**
| 選んだこと | 変わること |
|---|---|
| ピムを送る／連れて進む | 弁当と秘密のうろ（送る）／近道2か所（連れる）。年代記の文：「幼い子を家へ帰し…」／「幼い子とともに森を進み…」 |
| 小鹿を手当て／しない | 近道と、村の外の小鹿（手当て）。しない場合は何も失わない |
| 4人を見つけた順 | 最後に見つけた人が、報酬の一品物を渡す（どれを選んでも同じ強さ：`u_hans_axe`／`u_ben_whistle`／`u_roy_charm`／`u_pim_cap`） |

**小さな依頼（掲示板・町の人）**
1. 木の上の家々への手紙配り（樹上の村のつり橋を渡って5軒。報酬：お金と木登りの靴＝アクセサリ）
2. 薬草5種を集める（森の広場ごとに1種。報酬：薬の詰め合わせ）
3. 歌あわせ（リタの弟子と、歌の節を順に当てる遊び。§5 フェルン。報酬：段階ごとに品）
4. キノコの輪の謎（森の外の輪に正しい順で入ると、隠された宝箱が現れる。解決後）
5. どんぐり王子の噂（森の南の広場。レア魔物）

**ダンジョン**：迷いの森（2階、屋外、56×48 程度まで広げる）、千年樹（2階）。**回復の泉**：迷いの森1階の中ほど（木漏れ日の泉）、千年樹2階の根の間の手前。
**ボス**：狼の群れ頭（新規の編成、既存の狼系統から。救出の戦い）、根食らい `tr_b_rooteater`。ダストウィング `tr_b_moth` は迷いの森2階の歌の石を守る。
**報酬**：ページ、上の一品物（1つ）、ハンナからの `ac_tale_forest`（今のまま）。
**本筋とのつながり**：樵の休み小屋（#1）と、森の奥の空き小屋に **記録院の記録官の帳面** が落ちている。「歌の石の歌を写した。写したあと、村の子が歌えなくなった。報告すべきか」――写すと忘れる、の最初の証拠。

**前提**：砂嵐がやまず、オアシスの泉が枯れかけている。泉の水の源は、王墓のそばの「古い泉」。隊商の長ザイードは水の精霊への供え物を運ぶ隊を出したいが、護衛がいない。

**手がかり**

### 4.3 雪原（ユール）「冬至祭と籠城」— 章題「白竜と冬至の火」
**前提**：冬至の祭の前夜。春になっても吹雪がやまないのは、白竜が物語を受け取れず、心が凍ったため。村は祭をやれば春が来ると信じて準備をしているが、祭の物語の本が白紙になっていた。

**町に入ると**：村は祭の飾りつけの最中。雪のトンネル（§5 ユール）を子どもが走り回る。話しかけてこない。

**手がかり**
- 「冬至祭の支度」（村長ヨルン。支度の3つの仕事）
- 「白紙の物語の本」（火守りの娘ソーニャ。祭で読む物語が消えた）
- 「吹雪の中の遠吠え」（見張りの老人。夜ごと狼の声が近づいている）

**流れ（祭の支度 → 籠城 → 峰）**
1. **支度の3つ**（順番自由）：
   - 薪集め：村の外の雪の森で、倒木を3本（ワールドの近くの小さな林）。
   - 氷の灯籠：凍った池で氷を切り出す（釣り小屋の遊びの道具を借りる。§5 ユール）。
   - 物語の稽古：白紙の本の代わりに、村の年寄り3人から昔話を聞く。**どの話を祭で語るかを選ぶ**：「竜と娘の約束」「狼と猟師」「火を盗んだ子ども」。
2. **祭の夜**：灯籠がともり、選んだ話を主人公が語る（字幕の演出）。途中で吹雪が強まり、**氷の狼の群れ**が村を囲む。
3. **籠城（3波）**：村の門は3つ（北・東・西）。波ごとに、どの門を守るかを選ぶ。選んだ門で戦闘（2〜3戦の連戦、間に大かまどで回復）。
   - 守らなかった門は、村人が守る。**波ごとに1つだけ守れない門が出る**ので、そこは被害が出る（屋台が壊れる、倉が荒らされる）。被害は見た目と台詞と店の品ぞろえ（1段減る）だけで、失敗はない。

### 4.4 湿原（ロッホ）「町の中の犯人さがし」— 章題「霧の魔女と七つの鐘」
**前提**：霧の夜ごとに子どもが消える（すでに2人）。町の人は霧の館の魔女のしわざだと言い、今夜にも館に火をかけようと集まっている。

**町に入ると**：広場に松明を持った人だかり。演説しているのは怒った町人。止める人はいない。**話しかけても「よそ者は口を出すな」**。主人公が関わるのは、宿で母親のエマ（子どもが消えた）から話を聞いてから。

**調べる仕組み（推理）**
- 町は **昼と夜** を行き来する（宿で「夜まで休む／朝まで休む」。§6.6 の E9）。夜にしか会えない証人、夜にしか見えない足あとがある。
- 証拠は **6つ**。手がかり帳の地方のページに「証拠」として並ぶ（新しい画面は作らない）。
  1. 運河の岸の小さな足あと（夜）――館とは逆の、沼の方へ向かっている。
  2. 鐘楼の記録帳（鐘つきトビアス）――鐘が鳴らなくなってから、子どもが消えはじめた。
  3. 人形師ベッポの店――消えた子の顔に似た人形。ベッポは「頼まれて作った」と言う（依頼主は「霧色のマントの女」）。
  4. 子どもの絵（消えた子の妹）――「おばあさんが歌ってくれた。でも口が動いてなかった」。
  5. 霧の館の中（館1階）――館の主メルダの幽霊と会う（ボイス v_melda_manor_01〜05）。**メルダは子どもをさらっていない**。
  6. 沼の縁の鐘の歌の石碑――歌の最後の節が削れている。
- **容疑者**：霧の館の魔女メルダ／人形師ベッポ／鐘つきトビアス／「霧そのもの」。
- 証拠が4つ以上そろうと、町の集会所で **集会** を開ける（手がかり帳に「集会」が出る。行くかどうかは自由）。集会で1人（または霧）を名指しする。

**流れ**
1. エマの話 → 証拠集め（どこからでも）。
2. 館（2階）へ行けばメルダに会え、鐘の鍵と鐘の歌を受け取れる（今のまま）。館の中の人形の楽団が中ボス。
3. 集会で名指し：
   - **霧そのもの**（正解）：証拠の1・2・4・6のうち3つを示せば町の人が納得。人々と一緒に沼へ（町の人が沼の入口の霧の壁を松明で押し広げる演出）。
   - **メルダ／ベッポ／トビアス**（誤り）：その人が捕まる。その夜、**もう1人子どもが消える**。翌朝、新しい証拠が1つ出て（捕まった人には無理だった、と分かる）、集会をやり直せる。3回まで間違えられ、3回目のあとは正解の証拠が自然にそろう（詰まない）。
4. 鐘沈みの沼（1階、58×48 → 64×56 程度）：鐘を3つ鳴らす（今のまま）。霧が集まった中心で霧食らい（ボイス v_mistwitch_marsh_01、v_melda_marsh_01）。
5. 締め：子どもたちが沼の小島で眠っていたのが見つかり、朝の鐘が鳴る。

**選択と結果**
| 選んだこと | 変わること |
|---|---|
| 一度で正解 | 町長から `u_sleuth_hat`（探偵の帽子：レア率を少し上げる） |
| 間違えた | 捕まった人は解決後に釈放され、町が謝る場面が入る。間違えた回数で年代記の文が変わる（「町は一度、罪なき人を責めた…」）。報酬は減らさない（`u_sleuth_hat` の代わりに、捕まった人からのお詫びの品。同じ強さ） |

**小さな依頼**
1. 運河の渡し守の代役（竿の舟で客を3人運ぶ遊び。§5 ロッホ）
2. 迷い猫（夜の高床の下）

### 4.5 諸島（コーラル・ネレイ）「自分の船での航海」— 章題「帰らずの船長」
**前提**：霧の夜に幽霊船が出て、船を岩礁へ誘う。コーラルの港は閉じ、定期船以外は出ない。幽霊船を追うには、自分の船が要る。

**町に入ると**：港に出られない船が並ぶ。造船所の親方ドレイクが、仕上がったのに乗り手のいない船を前に腕を組んでいる。話しかけてこない。

**手がかり**
- 「港が閉じた」（港の親方。幽霊船の出る海域）
- 「乗り手のいない船」（造船所。帆を張るには、潮鳴りの洞窟の奥の「光る貝がら」を船首に付ける習わし）
- 「岬の村の歌」（酒場の老水夫。岬の村ネレイのマリナという人が、昔の舟歌を知っている）

**流れ**
1. 潮鳴りの洞窟（1階 → 2階に広げる）で光る貝がら（今のまま）。深みの大ダコが中ボス。
2. 造船所で船首に貝がら → **外洋船を手に入れる**（ここからワールドを自分で走れる）。
3. **海図の空白**：港の親方の海図には、幽霊船の出る海域の周りに空白が4つ。船で近くへ行くと海図が埋まる。4つのうち3つを埋めると、幽霊船の海域が絞れる（手がかり帳に出る）。空白の場所は、人魚の歌う岩（#34）、財宝ヤドカリの島（#35）、座礁した商船、灯台島（新しい小島。灯台守のいない灯台）。
4. **座礁した商船の選択**：岩礁に乗り上げた商船。「船員を助ける」（小舟を出して3往復の短い場面）／「積荷を拾う」（ティア宝箱3つ）。
5. ネレイでマリナに会う（ボイス v_marina_nerei_01）。舟歌の前半しか覚えていない。**人魚の歌う岩（#34）で後半の節を聞いていれば、マリナが最後まで歌える**。聞いていなければ、マリナが思い出すまで一晩（宿で1泊）。
6. 夜の桟橋でマリナが歌う（v_marina_pier_01）→ 海に霧 → **自分の船で霧の中へ** → 幽霊船に横づけして乗り込む（今の「桟橋に船が来る」を、自分の船で追う形に）。
7. 幽霊船（3階）：甲板 → 船室 → 船倉。船長室で亡霊船長グレン（ボイス v_glen_ship_01〜04）。
8. 締め：夜明けの桟橋でマリナとグレン（v_marina_dawn_01・02、v_glen_dawn_01）。今のまま。

**選択と結果**
| 選んだこと | 変わること |
|---|---|
| 船員を助ける | コーラルの港の評判が上がり、船乗り組合の店に一段上の品。商船の船長から宝の地図 その4 |
| 積荷を拾う | ティア宝箱3。港の評判は変わらない。商船の船長は後で町に来て、少しだけ嫌味を言う |
| 岩で節を聞いた／聞かない | 聞いた：一晩待たずに済み、マリナから `u_siren_comb` の対の品。聞かない：待つだけ（損はない） |

**小さな依頼**
1. 貝がら集め（諸島の浜に12種。見える貝がらの落ちもの＝小さな宝箱。全部で `u_shell_charm`）
2. 灯台島に灯をともす（燃料を運ぶ。以後、夜の海で灯台の光が見える）
3. 釣り（コーラルの桟橋。ユールと同じ遊びの海の版）
4. 船乗り組合の配達（島から島へ荷を運ぶ。外洋船を使う練習）
5. 星くじらの噂（#33）

**ダンジョン**：潮鳴りの洞窟（2階、潮の満ち引きで道が変わる：§6.4）、幽霊船（3階）。
**回復の泉**：洞窟1階の中ほど（潮だまりの泉）、洞窟の大ダコの手前、幽霊船2階の船室（船員の水樽→泉に置き換え）、船長室の手前。
**ボス**：深みの大ダコ `tr_b_octopus`、亡霊船長グレン `tr_b_captain`。
**報酬**：ページ、外洋船、`ac_tale_isles`（潮騒の耳飾り。マリナ）、潮見橋の水門（§2.5）。
**本筋とのつながり**：船長室の机の上に、グレンの航海日誌。途中からページが白い。表紙の裏に「写 記録院マレア分室 六十年前」――**記録院は六十年前から写していた**（ラザロ一人の企みではない、の手がかり）。
**今のものから使うもの**：洞窟・幽霊船のマップ、グレンとマリナの筋とボイス、ネレイの町。コーラルは段々の白い港町に作り直す。エンジンの船（`onShip`）を使う。

### 4.6 鉱山（ドヴァン）「二つの勢力と選択」— 章題「鍛冶神の誓い」
**前提**：七の層より下を掘った坑道が崩れ、鉱夫が閉じ込められた。町は二つに割れている。**鉱夫組合**（鉱山長ボルグ）は「救出のあと、下の層の鉱脈を掘らねば町が食えない」。**誓いの鍛冶衆**（鍛冶師ヘルガ）は「鍛冶神との誓いを守り、下の層を封じるべきだ」。

**町に入ると**：町の中央の昇降機の前で、組合と鍛冶衆がにらみ合っている。どちらも話しかけてこない。酒場は組合の、鍛冶場は鍛冶衆のたまり場。

**手がかり**

**流れ**

3. **両方の言い分を聞く小さな仕事**（どちらも受けてよい）：
   - 組合の仕事：町の家族に、閉じ込められていた鉱夫の無事を知らせる／組合の帳簿を見る（下の層を掘らないと冬を越せない家が何軒あるか）。
   - 鍛冶衆の仕事：誓いの碑の読めない文字を、山の隠者の庵（#15）の古い写しと照らす／鍛冶神の石像（ランドマーク）で祈りの文句を読む。
4. **選ぶ**（町の集会所。選んだ時点で決まる）：
   - **A 組合につく**：七の層を開く。鉄の番人と戦う（ボス。v_guardian_mine_02 のあと戦闘、勝つと v_guardian_mine_03）。深淵の鉱脈（#17）が開く。

   - **C 仲裁**（両方の仕事をすべてやると出る）：番人に「上の層の鉱脈だけを掘る」と誓い直す。番人と短い問答（選択肢3つ、どれでも進む）→ 眠る。町は両方の利を少しずつ得る。
5. 締め：選んだ道に応じて、町の昇降機の前での場面（A：組合の祝杯と、町を去る鍛冶衆／B：鍛冶場の火入れと、肩を落とす組合／C：両方が同じ卓で飲む）。

## 5. 町の個性（形・固有の施設・小さな遊び）

### 5.1 共通の決まり
- **形を変える**：今は12町のうち9町が「52〜56×40〜44・北の列に宿と酒場・中の列に店と広場・南の列に民家と門」。案では、町ごとに地形から形を決め、**門の向き・大きさ・高さ（段・階）・水の入り方** を変える。
- **施設の組み合わせを変える**：宿・道具屋はどの町にもある。武器屋・防具屋・酒場は町によって有無と形を変える（屋台、行商、鍛冶場と一体、など）。どの町にも **その町にしかない施設** を1つ以上。
- **小さな遊び**は、共通の部品 `R.Mini`（`src/systems/minigame.js` 新規）の2種類だけで作る：
  - **タイミング**：動く印を A で止める（釣り・ふいご・トロッコのブレーキ・渡し舟の竿）。
  - **順番・選択**：節や記号を順に当てる／問答に答える（歌あわせ・鐘の調律・試験・賭け・羊追い）。
  どれも1回30秒〜1分、失敗しても何も失わない（賭けのお金だけ）。報酬は段位ごとに1回だけ。
- **酒場**：どの町の酒場にも「噂の3人」（§3.3）。仲間の入れ替えはファロスだけ（A17）。酒場を置かない町（ネレイ・隠れ里）は、噂の人を宿か広場に置く。
- **掲示板**：10町と宿場。小さな依頼と事件の張り紙。
- 内装の密度は今の基準（DQ5 程度・通り抜けられる飾り・A2 の間引き）を守る。`check_density` の基準はそのまま。
- 絵：町のテーマ（`themeOf`）を町ごとに1つずつ持つ（今は10）。新しく **樹上・高床・雪のトンネル・地下の洞窟都市・段々の白い町・火口の段々・城壁の区画** の部品が要る（§7.3 の ART）。

凡例（下の見取り図すべて。1文字＝2×2マス程度の概略）：
`#` 壁・崖・岩　`^` 木・森　`~` 水　`=` 橋・桟橋・板の道　`:` 階段・坂・はしご　`.` 地面・道　`,` 草地・畑
`G` 町の出入口　`I` 宿　`T` 酒場　`S` 道具屋　`W` 武器屋　`A` 防具屋　`B` 掲示板　`H` 民家　`o` 井戸・泉・噴水　`*` その町の固有の施設　`n` 夜だけ開く所

## 6. ダンジョン

### 6.1 大きさの決まり
- 1フロアの大きさは今の **1.3〜1.6倍まで** 広げてよい（目安：一辺 44〜72マス）。
- ただし「入口から次の階段まで」は **80〜140歩**（今は60〜100歩）。いちばん遠いマスまで 200歩を超えない。
- 行き止まりは「先に何かある」ものを増やす（宝箱・書き付け・隠し通路の入口・泉）。何もない行き止まりは1フロア3つまで。
- 階の数は今のまま（本編36フロア）を基本にし、広げた分は寄り道のダンジョン（§2.7、約25フロア）で遊べる量を増やす。
- 通しの目安：本編のダンジョン1つを抜けるのに 30〜45分（今は約20〜30分）。

### 6.2 回復の泉（A21）
- **見た目**：石の水盤から澄んだ水が湧き、青白い光の粒が上る（2×2 マスの `obj:spring`、4コマのゆらめき）。遠くから見える光（床に淡い光の輪）。今の「休息の灯」（小さなランタン）より大きく、目立つ。
- **はたらき**：調べると HP・MP 全快、戦闘不能も起こす、控えも回復（今の `ev.rest()` と同じ）。**何度でも使える**。短い効果音と画面の青い明滅。
- **置き方**（全ダンジョン共通の規則。`check_springs`（新）で検査）：
  1. **各ダンジョンの途中に1つ以上**：入口から数えて全体の道のりの 40〜60% の所。1階だけのダンジョンでも中ほどに1つ。
  2. **ボスの前に1つ**（今の休息の灯の位置）。中ボスの前にも1つ。
  3. **長い道**：泉から泉（または入口）まで 150歩を超える所があれば、間にもう1つ。
  4. **隠し通路の先の小部屋**に「ご褒美の泉」を置いてよい（ダンジョン全体の3〜4割の隠し部屋のうち、いくつか）。
  5. 泉の周り（半径3マス）は魔物が出ない（今の休息の灯と同じ扱い）。
- **今の休息の灯26か所** は泉に置き換える（イベント `common_rest` は `common_spring` に名前を変えてもよいが、中身は `ev.rest()` のまま）。それに **1階と途中の泉を約30か所足す**。
- 泉は **ワープの行き先にはしない**（ワープは町とダンジョンの入口のまま）。代わりに「脱出」で戻ったあと、入口の石碑から **最後に触れた泉** へ一度だけ飛べる（手間を減らす。同じダンジョンの中だけ）。→ オーナーに確認（§8）。

### 6.3 宝箱の見え方（A21）
**描き方（`src/art/objects.js` の `obj:chest` を描き直す）**
- 大きさは 16×16 のまま（マス目の決まりを変えない）。**ふたを明るい赤茶と金の縁、胴は濃い木**。鉄の帯は明るい金に。
- **1px の暗い輪郭**（床の色によらず形が分かる）と、上の縁の **明るいふち取り**。
- **足元の影**（楕円、床に落とす）。
- **きらめき**：2〜3秒ごとに、ふたの角に4コマの光（小さな十字）。画面の中の宝箱が同時に光らないよう、位置でずらす。
- **開けた箱**：ふたが開き、全体を少し暗く・彩度を下げる。きらめきと明るいふち取りは消える。中は空（黒）。
- **レアの箱**（`obj:chest_rare`、p_rare）：今の紺と金をもっと明るく。きらめきを金色に、回数を多く。
- 町の宝箱（19個）も同じ絵。
- 「RS1 の地に合わせて色を落とした」という今の方針は、**宝箱だけは例外** とする（床の飾りではなく、見つけてほしい物なので）。

**検査（`tools/check_chests.js` 新）**
- 全マップのすべての宝箱について、宝箱の絵と「その宝箱が置かれた床のタイル」の見た目の差（明るさの差と色の差）を計算し、しきい値より小さいものを一覧にする。
- テーマごとのスクショ（木の床・砂・土・岩・雪・灰・水辺・本棚）に宝箱を並べた見本を `design/shots/` に撮り、目で確かめる。
