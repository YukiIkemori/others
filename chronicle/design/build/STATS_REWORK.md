## 1. 能力値の新しい尺度（A22）

### 1.1 方針
- 6 つの能力値は **0〜25**。キャラごとの固定値（`DB.companions[id].stats`・`DB.heroTypes[type].stats`）で、**レベルでは伸びない**（成長の伸びは 0。「わずかに伸びる」案は採らない: 装備の +1 の手応えが薄れ、稼ぎの効きが増えるため）。
- 装備で上がった後の値の上限は **40**（`CAPS.stat` 999 → 40。実際の最大は 25 + 装備の合計 ≈ 35）。
- HP・MP の伸びは今のまま（`K.HP` `K.MP` の曲線 × 成長の文字 × 体力の倍率 §2.2）。熟練度の伸びは SYSTEMS_REWORK と §5。
- 能力値ごとの働き（§2.2 の式がすべて）:

| 能力値 | 効くところ |
|---|---|
| 腕力 | 腕力の武器（剣・大剣・斧・杖の半分・槍の半分）の攻撃力 4.5%/点 |
| 体力 | 最大HP 2.5%/点 |
| 器用さ | 器用さの武器（短剣・弓・槍の半分）の攻撃力 4.5%/点、命中 +1/点、会心 +0.5%/点、技の威力 1%/点、技の状態異常の決まりやすさ 4%/点、技の閃き 4%/点 |
| 素早さ | 行動の速さ（旧の尺度で 3.4/点）、回避 +0.7/点、逃走・盗み（速さの差） |
| 知力 | 術力 4.5%/点、術の状態異常 4%/点、術の閃き 4%/点 |
| 精神 | 回復の術・技 4%/点、術防 3%/点、状態異常の防ぎ 0.5 ポイント/点 |

## 2. 式（担当 RULES＝rules.js、BATTLE＝battle.js・mon.js、GLIMMER は RULES の glimmer.js）

### 2.1 定数（`R.Rules.K` に足す・置き換える）
```js
ABIL: {
  mid: 16,            // 普通の値。abilMul(16, k) = 1
  cap: 40,            // 装備込みの上限（CAPS.stat も 40）
  minMul: 0.5,        // どの倍率もこれより下げない
  atk: 0.045,         // 物理の攻撃力（武器の系統の能力値。§4.3.4 の stat の平均）
  mag: 0.045,         // 術力（知力）
  heal: 0.04,         // 回復の術・技（精神）
  tech: 0.01,         // 技（物理）の威力（器用さ）
  vit: 0.025,         // 最大HP（体力）
  mdef: 0.03,         // 術防（精神）
  sf: 0.04,           // 状態異常の決まりやすさ（術 = 知力、技 = 器用さ）
  gf: 0.04,           // 閃き（術 = 知力、技 = 器用さ）
},
WA: [11, 22, 35, 52, 71, 96, 122, 156, 193, 246],     // 武器の攻撃力・術力の土台（ティア 0〜9）。§2.3
GRADE_ATK: { normal: 1, rare: 1.06, super: 1.12 },     // 武器の atk・mag（fillItem）
GRADE_DEF: { normal: 1, rare: 1.10, super: 1.20 },     // 防具の def・mdef（fillItem）
ACC_W: [1, 1, 1, 2, 3, 4, 5, 7, 8, 10],                // 通常の腕輪・耳飾りの atk・mag（§3.2）
HIT:  { base: 98, per: 1.0, min: 20, max: 100, blind: 0.5, mon: 95 },     // 旧 base 90 + dex/4 → 器用さ 16 で 98
CRIT: { base: 4, per: 0.5, mult: 1.5, cap: 60, mon: 2, boss: 3 },         // 旧 2 + dex/16 → 16 で 4
EVA:  { base: 6, per: 0.7, cap: 60, nimble: 25 },                         // 旧 agi/5 → 16 で 6
SPD:  { base: 34, per: 3.4 },                                             // 旧 agi（魔物の agi と同じ尺度）
MDEF: { flat: 16 },                                                       // 旧 floor(精神/2) の置き換えの土台
STATUS: { mndPer: 0.005, resistCap: 0.9, pCap: 0.95, bossDebuff: 0.5 },  // 旧 mndDiv 500
SF:  { min: 0.6, max: 1.8 },   // 旧 base 128 / div 168 は削除

// 削除: STAT_K, VIT, MNDF, HIT.dexDiv, CRIT.dexDiv, EVA.agiDiv, STATUS.mndDiv, GLIM.gf.base/div, U（品の能力値の単位。PM のフォールバックからも消す）
```

- `R.Rules.abilMul(a, k) = Math.max(K.ABIL.minMul, 1 + k * ((a == null ? K.ABIL.mid : a) - K.ABIL.mid))` を公開し、下の式はすべてこれを通す（battle.js・mon.js・glimmer.js は `R.Rules.abilMul` を呼ぶ。rules が無い時のフォールバックは同じ式を各ファイルに 1 行で持つ）。
- `K.W` は残す: `formula:'tier'`（道具・魔石のダメージ）と値段・sim の目安だけが使う。武器の数値は `K.WA`。

### 2.2 式の一覧（旧 → 新）
a = その能力値（装備込み、0〜40）。M(a, k) = `abilMul(a, k)`。

| 値 | 旧 | **新** | 16 / 21 / 25 / 10 のとき |
|---|---|---|---|
| 能力値（`finalStats`） | (基本 + 装備の stats) × (1 + XPct/100)、0〜999 | **基本 + 装備の stats、0〜40**（`XPct` は廃止。§3.1） | — |
| 攻撃力 atk(枠) | round((W + m.atk) × (64 + S)/64) | **round((W + m.atk) × M(S, 0.045))**、W = 品の atk（`K.WA[T] × mult × GRADE_ATK`）、S = 系統の能力値の平均 | ×1 / 1.225 / 1.405 / 0.73 |
| 術力 mag | round((Wm + m.mag) × (64 + 知力)/64) | **round((Wm + m.mag) × M(知力, 0.045))**、Wm = 武器 2 本の mag の大きい方（無ければ `K.UNARMED.mag`） | 同上 |
| 最大HP | round(HPlv × GH × (160 + 体力)/200) × … | **round(HPlv × GH × M(体力, 0.025))** × (1 + hpPct/100) + bonus.hp | ×1 / 1.125 / 1.225 / 0.85 |
| 守備力 def | 防具の def + m.def | 変えない（防具の def は `GRADE_DEF` 込み） | — |
| 術防 mdef | 防具の mdef + floor(精神/2) + m.mdef | **round((防具の mdef + m.mdef + 16) × M(精神, 0.03))** × (1 + mdefPct/100) | ×1 / 1.15 / 1.27 / 0.82 |
| 命中 hit(枠) | 90 + floor(器用さ/4) + 系統 + 品 + m.hit | **round(98 + 1.0 × (器用さ − 16))** + 系統 + 品 + m.hit | 98 / 103 / 107 / 92 |
| 会心 crit(枠) | 2 + floor(器用さ/16) + … | **floor(4 + 0.5 × (器用さ − 16))** + 系統 + 品 + m.crit（0〜60） | 4 / 6 / 8 / 1 |
| 回避 eva | floor(素早さ/5) + 盾 + m.eva | **max(0, round(6 + 0.7 × (素早さ − 16)))** + 盾 + m.eva（0〜60） | 6 / 10 / 12 / 2 |
| 行動の速さ spd | 素早さ + m.spd | **max(1, round(34 + 3.4 × (素早さ − 16)) + m.spd)**（旧の尺度。魔物の agi と比べる） | 34 / 51 / 65 / 14 |
| 行動順 | spd × 段階 × rand(0.75, 1) | 変えない（味方は新しい spd、魔物は agi） | — |
| 逃走 | 速さの平均の比 | 変えない（spd） | — |
| 盗み | 0.35 + (素早さ − 魔物の素早さ)/200 | **0.35 + (spd − 魔物の agi)/200**（`u.stat('spd')`。battle.js 1618 行の `stat('agi')` を `stat('spd')` に） | — |
| 物理ダメージ | A × P × … × 熟練 | **技（`ctx.kind === 'tech'` で `formula:'phys'`）だけ × M(器用さ, 0.01)** を足す。ほかは変えない | ×1 / 1.05 / 1.09 / 0.94 |
| 術ダメージ | M × SP × … | 変えない（術力に知力が入っている） | — |
| 回復（術・技） | 最大HP × pct × MNDF × (1 + healPct) × 熟練 | **MNDF を HEALF = clamp(M(精神, 0.04), 0.6, 2.0) に**（mon.js `mndf` → `healf`） | ×1 / 1.2 / 1.36 / 0.76 |
| 状態異常の決まりやすさ SF | clamp((128 + S)/168, 0.6, 2.0) | **clamp(M(S, 0.04), 0.6, 1.8)**、S = 術・術扱いの技は知力、技は器用さ（battle.js `sf`） | ×1 / 1.2 / 1.36 / 0.76 |
| 状態異常の防ぎ | min(0.9, 精神/500 + statusResist) | **min(0.9, 0.005 × 精神 + statusResist)** | 8% / 10.5% / 12.5% / 5% |

## 5. 熟練度の速さ（A22 と SYSTEMS_REWORK §1 の照合）

### 5.1 目標と、SYSTEMS_REWORK のままの見込み

SYSTEMS_REWORK の模型（1 戦 3 行動、主な武器 62% = 1.86 点/戦、弓だけ 2.76、2 つ目 0.9、術師 0.75 回 = 1.5 点・1.5 回 = 3 点、開始 S 25 点）で、SYSTEMS_REWORK の定数のままだと:

|---|---|---|---|---|
| 序章の終わり | 6（90 点） | 9 | 6 | 9 |
| T0 のダンジョンの入口（45 戦目） | 11〜12 | 15 | 8 | 12 |
| T0 のダンジョンの中ほど（70 戦目） | 13 | 18 | 9 | 14 |
| T0 の終わり | 16 | 20 | 10 | 15〜16 |
→ 主な武器・よく唱える術師で目標を 3〜5 段上回る。

### 7.3 盗みの順番（担当 BATTLE、battle.js `steal`・`autoSteal`・`stealPick`・`stealable`）
1. 盗む（技の `steal`・コマンド）: 成功の判定は旧のまま `stealChance`（§2.2 で速さを `spd` に）。
2. 成功したら、**先に盗み専用の枠を判定**: 魔物が `drops.steal` を持ち、その戦闘でまだ取っていない（`t.stolenSt` が無い）なら
   `p = min(K.STEAL.only.cap, (1 / rate) × (1 + stealPct/100))`（stealPct は盗んだ人の mods。ティッタ +50、手袋など）、ついでに盗む（`autoSteal`）経路では × `K.STEAL.only.autoMul`（0.5）。当たれば盗み専用の品を取る（`grade:'super'`, `stealOnly:true`）。
3. 外れたら旧の `stealPick`（レア枠 → 通常枠）。
4. 使い切り: **通常の魔物・レア魔物**は、何かを盗んだら `t.stolen = true`（旧のまま。盗み専用を取った時も）。**ボス**は通常・レアの枠を盗むと `t.stolen = true` になるが、盗み専用の枠は `t.stolenSt` だけで管理し、**取れるまで成功のたびに判定する**（ボスは 1 回しか戦えないため。`stealable(t)` は `t.stolenSt` が無く `drops.steal` があれば true）。
5. 取った時: `{t:'gain', item, grade:'super', stolen:true, stealOnly:true, u, mon}` を出す（bui は超レアのポップアップ A12 と同じ演出）、文「{名前}は★{品}を盗んだ！」、`R.State.noteDrop(t.id, 'steal', {stolen:true})`。
6. 金色の個体・召喚された魔物: 金色は率 ×2（`GOLDEN` の考えに合わせる）、召喚（`summoned`）は盗み専用の枠なし。
```js
STEAL: { …旧…, only: { cap: 0.5, autoMul: 0.5, golden: 2 } },   // rate はデータ（32 / 16 / 8）
```
- 率の目安: 通常の魔物 1/32（ティッタ 1/21、ティッタ＋黄金の手袋 1/16）、レア魔物 1/16（ティッタ 1/11）、ボス 1/8 を成功のたび（盗みの成功率はボス ×0.5 なので、ティッタが毎ターン盗んで 1 戦 10 ターンで 取れる率 ≈ 45%）。

### 7.4 ドロップと図鑑
- `R.Mon.rollDrops` は `drops.steal` を **見ない**（倒しても落ちない）。`dropChances` も旧のまま。
- 図鑑（`g.book.mon[id]` の枠）に `steal` を足す。表示は「盗み　？？？」（未入手）→ 品の名前（入手後）。`drops.steal` の無い魔物には行を出さない（担当 UI、menu_book.js か図鑑の画面）。
- 盗み専用の品の詳細（Y）に入手の手がかりは出さない（図鑑の「？？？」だけ）。

### 7.5 オート・AI
- A26 でプレイヤーのオートは無い。sim の AI（battle_ai.js の `autoSteal` を持つ人の通常攻撃）は旧のまま。盗みのコマンドを AI が選ぶ規則は足さない。
