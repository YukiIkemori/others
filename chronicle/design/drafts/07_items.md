# 07 装備・道具（DESIGN.md 用ドラフト）

この章は、武器・防具・アクセサリ・道具・大事なもの、店の品ぞろえ、ティア宝箱のプール、魔物のドロップに置く品を決める。
実装担当は **weapons（A9）**（武器）と **gear（A10）**（防具・アクセサリ・道具・大事なもの・店・プール）。

- 数値の式（W・U・D・PRICE、レア度の倍率、守備の割合）は **02 成長章が正**。この章はその式を**どの品にどう当てるか**を決める。
- id の形・装備枠・種別・mods のキーは 01 エンジン章に合わせた。足したものは §0 と §3.7 にまとめた。
- 04 キャラ章が固定した初期装備 20 品（id・名前・種別）は、そのまま T0 の通常品として入れた。
- 表の数値はすべて node のスクリプトで作った（式どおりに計算した値）。品の名前は、全角 9 字以内・重複なし・使ってはいけない名前（§14.3）を含まないことを検査した。説明文 `desc` は全角 20 字 × 2 行以内。

## 0. 決定の一覧（Part B・他章からの変更と具体化。理由つき）

| # | 決定 | 理由 |
|---|---|---|
| 0.1 | 通常品は**系列（line）**で作る。系列 = 枠 × 重さ（武器は系統）× 能力値の振り方。1 系列に **T0〜T9 の 10 品**。武器 12 系列（11 系統＋杖の精神の系列）、防具 30 系列（5 部位 × 6）、能力のアクセサリ 6 系列。計 **480 品**。これに補助のアクセサリ（mods だけの通常品）51 品。 | 成長章 §3.7 の検算（全身を通常の知力装備）には、**どの枠にも知力だけの品**が要る。腕力・器用さも同じ。系列にすると、どのティアでもどの型の一式もそろい、店とプールを機械的に作れる。 |
| 0.2 | 通常品の名前は「**素材（ティアごと）＋の＋品の名**」を基本にする（重装は金属、軽装は革、布は織物）。 | 名前でティアが分かる（鉄 → 鋼 → 黒鋼 → 銀 → …）。300 を超える通常品でも名前がぶれない。 |
| 0.3 | レア品は **5 つの帯 T1・T3・T5・T7・T9** に作る（130 品）。ティア T の宝箱・魔物は `RB(T) = [1,1,3,3,5,5,7,7,9,9][T]` の帯のレア品を使う。 | 魔物の段は 2 ティアずつ出る（成長章 §14.1: 4 段の出始め [0,2,4,6]）。1 つの帯で 2 ティアを受け持てば、レア品 1 つ 1 つを濃く作れる。 |
| 0.4 | T9 の品（通常・レア・超レア）は**クリア後だけ**（裏ダンジョンの宝箱・魔物、クリア後のリュートとビブリアの店）。 | 成長章 0.11（ティア 9 = クリア後）。 |
| 0.5 | 超レアは**1 種類の魔物の超レア枠だけ**に置く一品物。品の tier は、その魔物の段が**最後に出るティア**（§6.1 の `srTier`）。id は `<接頭辞>sr_<鍵>`。 | 段の出始めのティアで作ると、次の段が出るまでの 2 ティアで弱くなる。最後のティアに合わせると、手に入れた後もしばらく一線で使える。 |
| 0.6 | **レア魔物（ティアで伸びるゾーンにいるもの）の品は「遺物」**＝ティアに依らないアクセサリ（能力値の**割合**と mods だけ。固定の能力値なし）。レア枠と超レア枠は、そのレア魔物だけの品。**通常枠は `p_seed`（最大値を伸ばす実）**。 | レア魔物はティア 0〜7 のどこでも出る（`scale:'tier'`）。固定の数値の品だとティア 0 で出れば強すぎ、ティア 7 で出れば弱すぎる。割合の品なら、いつ手に入れても価値がそろう。成長章 §10.3 の「3 つの枠すべて専用」は、レアと超レアの 2 枠にした（通常枠まで専用にすると品が 70 近く増えて、どれも薄くなる）。 |
| 0.7 | **物語の報酬（一品物 12 個）も、ティアに依らない**アクセサリにする（ティアが固定の場面の 2 つを除く）。 | 地方の報酬は、どの順番でクリアしても同じ価値にしたい（Part A「どの順番でも崩れない」）。 |
| 0.8 | mods に 7 つのキーを足す: `defPct mdefPct takenPct noSpell hpLoss autoRevive autoCounter`。武器の項目に 4 つ足す: `vs drain sealTech metalHit`（§3.7）。 | Part A の例（「知力が大きく上がるが防御が低い」「攻撃 ×1.5 だが技が使えない」「倒れても起き上がる」）を、今のキーだけでは書けない。 |
| 0.9 | 装備の `mag`（術力の元に足す。成長章 §16）は **レア = T、超レア = 2T**（成長章の目安「指輪 T×2」から下げた）。T8 の超レアの一式ごとに、**威力の割合の mods（`physPct`/`magicPct`）の合計は +30 まで**。 | `mag` は武器とアクセサリ 2 つで重なる。目安のままだと、全身を超レアで固めた術師の術力が成長章 §3.7 の S（435）の 1.5 倍を超える。 |
| 0.10 | ワープ・ダンジョン脱出は**大事なもの**（`k_quill` `k_bell`。ワールド章 0.6）。同じ働きの道具は作らない。 | 同じ働きを 2 つ作らない。「管理はシンプルに」。 |
| 0.11 | ボスの確定ドロップは**プール**から引く（`drops.normal = {pool:'p_boss', rate:1}`）。戦闘のティアで中身が決まる（§12.3）。クリア後の 2 体（魔王の残影・円環竜）だけは、超レア枠を持つ（1/4。再戦で狙う）。 | ボスはティア 0〜7 のどこで戦うか分からない。成長章 §10.1 の「ボスは超レアなし」は、再戦できる 2 体だけ例外にした（ワールド章 §12 の「超レアの品を狙うための再戦」）。 |
| 0.12 | ティア宝箱のプールは **10 段（ティア 0〜9）**。宝箱のティアは `def.tier` → マップの `chestTier` → `R.Game.tier` の順に決まる（§12.1）。 | 裏ダンジョン（ティア 9）の宝箱を、エンジン章 §5.5 の仕組みのまま作るため。 |
| 0.13 | 店の品ぞろえは、系列の一覧から `R.onData` で作る（§11.1）。段に `cond` を書ける（ワールド章の依頼と同じ）。 | 34 店 × 10 段を手で書くと必ず食い違う。 |
| 0.14 | `mpCostPct`・`wpCostPct` の合計は **−50 で止める**（rules への依頼）。 | 装備で重なると、大技の消費がほぼ 0 になる。 |
| 0.15 | 数値（`atk mag def mdef eva stats price`）は**データに書かない**。データには `tier grade units` などを書き、各ファイルの `R.onData` で `R.Rules.fillItem`（§2.9）が埋める。 | 数値の元は `R.Rules.K` の 1 か所（成長章 §18.1）。バランスを直したら全品が一度に直る。 |
| 0.16 | 手の重装・体力の系列の名前は「〜の手甲」ではなく「**〜のガントレット**」にした。 | 「銀の手甲」がロマサガ1の品名「銀の手」を部分一致で含むため（検査 §14.3）。 |

## 2. アイテムのデータの形（`R.DB.items[id]`。規則）

### 2.1 共通の項目
| 項目 | 必須 | 値 | 意味 |
|---|---|---|---|
| `name` | ○ | 全角 9 字まで | |
| `type` | ○ | `weapon shield head body hands feet acc consumable key` | エンジン章 §3.1 |
| `grade` | ○（装備・道具） | `normal rare super` | 大事なものは書かない |

### 2.3 防具（`type: shield head body hands feet`）
| 項目 | 必須 | 値 | 意味 |
|---|---|---|---|
| `weight` | ○ | `heavy light cloth` | 重装・軽装・布（成長章 §3.3） |
| `def` `mdef` | 自動 | 数 | `fillItem`。クセで 0 にする品だけ `def:0, mdef:0` を書く（`fillItem` は書いてある値を変えない） |
| `eva` | 自動（盾） | 数 | 盾だけ。重装 8・軽装 5・布 2 |
- 盾の枠には、布の「術書」「護符」も入る（成長章 §3.3）。両手持ちの武器を持つと盾は付けられない（エンジン章 §5.3 規則 2）。

### 2.4 アクセサリ（`type:'acc'`）
- 守備・術防を持たない。能力のアクセサリは `units` 1 単位。補助のアクセサリ・遺物・報酬は `units` を持たない（能力値なし）。

### 2.5 道具（`type:'consumable'`）
```
{ name, type:'consumable', grade, price, desc, icon?,
  use: { target, effects:[…], fx, battle:bool, field:bool },
  stone?: '<属性>' }                        // 魔石だけ。閃きの ctx.stone（術章 §10）と ctx.elements = [属性]
```
- `effects` の型はエンジン章 §3.1 と術章 §3.3 のもの（`heal{pct}` `revive{pct}` `healMp{pct}` `healWp{pct}` `cure` `buff` `damage{formula:'tier'}` `escape` `scan` `encounter` `grow`）。
- 回復は割合（成長章 §6.4 の「道具の回復」。`itemPct` が効く）。`formula:'tier'` のダメージは `SP × W(Tb)`（成長章 §6.3）。
- `grow` は `{type:'grow', stat:'hp'|'mp'|'wp', n}`。CharState の `bonus[stat]` に n を足す（エンジン章 §4.2）。上限は `bonus.hp ≤ 200`、`bonus.mp ≤ 30`、`bonus.wp ≤ 30`（上限に達したら「これ以上は効かない」と出して使わない）。

### 2.6 大事なもの（`type:'key'`）
```
{ name, type:'key', price:0, desc, use?: { target:'self', effects:[{type:'teleport'}|{type:'exit'}], field:true, battle:false } }
```
- 大事なものは**使っても減らない**。捨てられない。売れない。数は 1 つ（2 つ目は渡さない）。
- 使えるのは `k_quill`（ワープ）と `k_bell`（脱出）だけ。`k_chronicle` はメニューの「年代記」を出す条件（エンジン章 §5.12）。

### 2.7 説明文 `desc` の書き方
- **通常品**（`fillItem` が作る）: 1 行目 = 武器なら `DB.weaponTypes[w].desc`、防具なら重さの文（重装「重くて守りが固い。」／軽装「軽くて動きやすい。」／布「術から身を守る。」）、能力のアクセサリなら「身につける飾り。」。2 行目 = 「<能力値の名>が上がる。」（2 つなら「腕力と器用さが上がる。」）。
- **レア以上・補助のアクセサリ・遺物・報酬**: 表（§4.4〜§8）の文をそのまま使う。形は「特殊効果の文 → クセの文（「ただし〜」）」。

### 2.8 表示（menu・bui の担当へ）
- レア度の印: 通常は印なし、レア **★**（黄 `#f8d838`）、超レア **★**（桃 `#ff88d0`）。名前の色も同じ。遺物は超レア・レアと同じ印。
- 報酬（`unique`）は印の代わりに **◆**（水色）。
- アイコン `icon` の既定: 武器 `icon:<wtype>`、盾 `icon:shield`、頭 `icon:head`、体 `icon:body`、手 `icon:hands`、足 `icon:feet`、アクセサリ `icon:acc`、回復・蘇生・実 `icon:herb`、MP・WP・治療・香・玉 `icon:potion`、魔石 `icon:el_<属性>`、大事なもの `icon:key`。
- 装備の画面・店では、`mods` の中身（特殊効果・クセ）を `desc` の 2 行で見せる。数値は ↑↓ の比べ方（能力値・攻撃・術力・守備・術防・回避・会心）で見せる。

### 2.9 数値を埋める関数 `R.Rules.fillItem(it)`（rules が rules.js に置く。items_*.js は `R.onData` で呼ぶ）
```js
// 02 成長章 §3 の式。書いてある値は変えない（クセの def:0 などを守るため）。
R.Rules.fillItem = function (it) {
  const K = R.Rules.K, T = it.tier || 0, g = it.grade || 'normal', GM = K.GRADE_MULT[g];
  const U1 = (u) => Math.max(1, Math.round(u * K.U[T])) * GM;                 // gearStat
  const SK = { s: 'str', v: 'vit', d: 'dex', a: 'agi', i: 'int', m: 'mnd' };
  if (it.units && !it.stats) {
    it.stats = {};
    for (const m of it.units.matchAll(/([svdaim])(\d)/g)) it.stats[SK[m[1]]] = U1(+m[2]);
    for (const [k, v] of Object.entries(it.statsAdd || {})) it.stats[k] = (it.stats[k] || 0) + v;   // クセの負の能力値
  }
  if (it.type === 'weapon') {
    const w = K.WTYPE[it.wtype];
    if (it.atk === undefined) it.atk = Math.round(K.W[T] * w.mult);
    if (it.mag === undefined) it.mag = Math.round(K.W[T] * w.magMult);       // 杖 1.0、ほか 0.5
    if (R.DB.weaponTypes[it.wtype] && R.DB.weaponTypes[it.wtype].twoHanded) it.twoHanded = true;
  } else if (K.SLOT_SHARE[it.type] !== undefined) {
    const wt = K.WEIGHT[it.weight], D = K.D(T), sh = K.SLOT_SHARE[it.type];
    if (it.def === undefined) it.def = Math.round(sh * D * wt.def);
    if (it.mdef === undefined) it.mdef = Math.round(sh * D * wt.mdef);
    if (it.type === 'shield' && it.eva === undefined) it.eva = wt.eva;
  }
  if (it.price === undefined && it.type !== 'consumable' && it.type !== 'key')
    it.price = Math.round(K.PRICE[T] * K.PRICE_SLOT[it.type] / 10) * 10 * { normal: 1, rare: 3, super: 6 }[g];
  if (!it.desc) it.desc = R.Rules.autoDesc(it);                              // §2.7 の通常品の文
  return it;
};
// 各 items_*.js の最後:  R.onData(() => { for (const id of MY_IDS) R.Rules.fillItem(R.DB.items[id]); });
```
- `K.PRICE_SLOT = { weapon:1.6, body:1.4, shield:1.0, head:0.8, hands:0.6, feet:0.6, acc:1.2 }` を `R.Rules.K` に足す（成長章 §3.6 の係数）。
- rules が未完成の間、items_*.js は同じ関数を自分のファイルの中に置いてよい（`R.Rules.fillItem || localFill`。定数は成長章 §3.1 の表の値）。
- 店・プールの `onData` は id と `line`・`tier`・`grade`・`src` だけを見るので、数値を埋める順番に依らない。

## 3. 数値の作り方（規則）

### 3.1 ティア表（成長章 §3.1 の再掲）と能力値の単位
`W = [8,14,21,30,40,51,64,78,94,112]`、`U = [1,1.5,2,2.5,3,3.5,4,4.5,5,6]`、`D(T) = 70 + 30T`、`PRICE = [70,160,290,450,660,900,1200,1500,1900,2600]`。
`gearStat(T, 単位, grade) = max(1, round(単位 × U(T))) × {normal 1, rare 2, super 3}`。**能力値ごとに**計算する（`s1d1` なら腕力と器用さに 1 単位ずつ）。

| T | U | 1単位 通常/レア/超レア | 2単位 通常/レア/超レア |
|---|---|---|---|
| 0 | 1 | 1 / 2 / 3 | 2 / 4 / 6 |
| 1 | 1.5 | 2 / 4 / 6 | 3 / 6 / 9 |
| 2 | 2 | 2 / 4 / 6 | 4 / 8 / 12 |
| 3 | 2.5 | 3 / 6 / 9 | 5 / 10 / 15 |
| 4 | 3 | 3 / 6 / 9 | 6 / 12 / 18 |
| 5 | 3.5 | 4 / 8 / 12 | 7 / 14 / 21 |
| 6 | 4 | 4 / 8 / 12 | 8 / 16 / 24 |
| 7 | 4.5 | 5 / 10 / 15 | 9 / 18 / 27 |
| 8 | 5 | 5 / 10 / 15 | 10 / 20 / 30 |
| 9 | 6 | 6 / 12 / 18 | 12 / 24 / 36 |
- 2 単位の品を 1 単位ずつに分けると、T1・T3・T5・T7 で合計が 1 だけ多くなる（例 T1: 2 単位 3 に対し、1＋1 単位 2＋2）。分けた系列（槍・棍棒・刀・体術・鞭）は「力が散る」ので、その分の小さなおまけとしてそのままにする（検査も同じ式で計算する）。

### 3.2 通常品（`grade:'normal'`）
| 部位 | 能力値の単位 | ほかの数値 |
|---|---|---|
| 武器 | 2（系列の `units`） | `atk = round(W(T) × 系統の倍率)`、`mag = round(W(T) × 術の倍率)`（杖 1.0、ほか 0.5）。命中・会心・属性・追加効果なし |
| 体 | 2 | `def = round(0.40 × D(T) × 重さの守備)`、`mdef = round(0.40 × D(T) × 重さの術防)` |
| 盾 | 1 | 0.20 × D、`eva` 重装 8・軽装 5・布 2 |
| 頭 | 1 | 0.15 × D |
| 手 | 1 | 0.10 × D |
| 足 | 1 | 0.15 × D |
| アクセサリ | 1（能力の系列）／0（補助） | 守備なし。補助は mods だけ（§4.4） |
- 重さの係数: 重装 守備 1.00・術防 0.20 ／ 軽装 0.65・0.35 ／ 布 0.40・0.60（成長章 §3.3）。
- 通常品は特殊効果もクセも持たない（補助のアクセサリを除く）。

### 3.3 レア品（`grade:'rare'`）
- 能力値 ×2（`gearStat` の rare）。**攻撃・術・守備・術防・回避は同じティアの通常品と同じ**（成長章 §3.2）。
- **特殊効果 1 つ**（§3.5 のレアの大きさ）。**クセ**（§3.6 の弱い方）は付けても付けなくてもよい（今の 130 品のうち 10 品）。クセを付けた品だけ、重さと違う能力値に振ってよい。
- 入手: 魔物のレア枠（1 品を最大 3 種類の魔物まで）、`p_rare` の宝箱、地方ボスの確定ドロップ `p_boss`（§12）。**店では売らない**。
- 帯: ティア T の宝箱・ボスは `RB(T) = [1,1,3,3,5,5,7,7,9,9][T]` のレア品。魔物のレア枠は §6.1 の `srTier` の帯（`srTier` が偶数なら 1 つ下の帯。9 だけは 9）。

### 3.4 超レア品（`grade:'super'`）
- 能力値 ×3。攻撃・術・守備などは通常品と同じ（下げるのはクセのときだけ）。
- **特殊効果 1〜2 つ**（§3.5 の超レアの大きさ）＋ **クセ 1 つ**（§3.6 の強い方。付けない品は全体の 2 割まで）。
- 重さと違う能力値に振ってよい（クセがあれば）。武器の `units` は 2 単位を 1 つの能力値に寄せてよい（例 鞭 `d2`）。
- **1 つの超レア品は、ちょうど 1 種類の魔物の `drops.super` にだけ置く**。宝箱・店・盗み・報酬では手に入らない（成長章 §10.1）。金色の個体は元の魔物と同じ品を落とす。
- 1 つの T8 超レアの一式（§6.5 の知力・腕力・器用さの 9 品ずつ）の中で、`physPct`・`magicPct` の合計は +30 まで、`mag` の合計は +16 まで（0.9）。

### 3.7 新しく足す mods のキーと武器の項目（rules・battle への依頼。エンジン章 §5.16・成長章 §16 に加える）
| キー | 種類 | 働き（規則） | 実装 |
|---|---|---|---|
| `defPct` `mdefPct` | 数（%） | 守備・術防の最終値に `× (1 + x/100)`（成長章 §4 の最後。最低 0） | rules `stats()` |
| `takenPct` | 数（%） | その人が受けるダメージ（物理・術・ブレス・固定・継続）に `× (1 + x/100)`（丸めの前。最低 1） | battle |
| `noSpell` | true | 術のコマンドが出ない（`commands(c)` から外す）。術の閃きも起きない（術を使えないため） | rules `commands` |
| `hpLoss` | 数 | 手番の終わりに最大HP の x% を失う（HP 1 は残る。戦闘の中だけ） | battle |
| `autoRevive` | 数（0〜1） | 戦闘不能になった瞬間、1 戦に 1 回だけ HP = 最大HP × x で起き上がる（「{name}は立ち上がった！」）。即死にも効く | battle |
| `autoCounter` | 数（0〜1） | 敵の単体の物理攻撃を受けた後、生きていて動けるなら x の確率で武器1（空なら武器2、両方空なら素手）の物理 1.0 で反撃（1 回の敵の行動につき 1 回。技章 §2.4-A の反撃と同じ処理。反撃の構えと同時なら構えだけ） | battle |
| 武器 `vs` | `{key:倍率}` | その枠の攻撃・技の物理ダメージに掛ける（技の `vs` と掛け合わせる。キーは種族・旗） | battle |
| 武器 `drain` | 0〜1 | その枠の攻撃・物理の技で与えたダメージの x を自分の HP に（技の `drain` とは大きい方） | battle |
| 武器 `sealTech` | true | その枠のコマンドは「攻撃」だけ。その枠の閃きは起きない | rules `techList`・battle |
| 武器 `metalHit` | true | その枠の**通常攻撃**が鋼の魔物に 3（会心 4） | battle |

- `mpCostPct`・`wpCostPct` は合計を −50 で止める（0.14）。
- 魔物は上の新しいキーを使わない（`takenPct` などは味方の装備だけ）。

### 3.8 値段

- 遺物: レア 1500・超レア 3000（売値 750・1500）。報酬: 0（売れない）。

## 6. 超レア（一品物。`grade:'super'`、`src:'super'`）

### 6.1 決まり（規則）
1. **出現表（`DB.encounters`）に出る魔物（鋼の魔物を含む）1 種類につき、超レア品がちょうど 1 つ**。レア魔物は §7。ボスとイベントだけの魔物は持たない（例外はクリア後の 2 体。0.11）。
2. 品の tier = `srTier(魔物)`:
   ```
   段 k の出始め = DB.lineages[L].stages[k].tier（成長章 §14.1）
   srTier = k が最後の段なら 8、そうでなければ（次の段の出始め − 1）
   ティア 9 に固定のゾーン（裏ダンジョン）にしか出ない魔物は 9
   ```
   例: 4 段の系統 [0,2,4,6] → 1 段目 1、2 段目 3、3 段目 5、4 段目 8。5 段 [0,2,4,6,8] → 1・3・5・7・8。3 段 [0,3,6] → 2・5・8。
3. レア枠（1/32）には、`srTier` の帯（奇数ならそのまま、偶数なら 1 つ下、9 は 9）のレア品を置く。1 つのレア品は 3 種類の魔物まで。レア枠の 3 分の 1 までは、レアの道具（`i_lifedew` `i_grace` `i_phoenix`。T4 以上の魔物）でもよい。
4. 通常枠（1/8）には、`srTier` 以下のティアの道具（§9）か、その tier の通常品を置く。
5. 金色の個体は元の魔物と同じ品を落とす（確率は成長章 §10.2）。

### 6.2 既定の割り当て（モンスター章が何も書かなかったときの形。書けば上書きできる）
**枠**（段の番号 k。系統の番号 = `DB.lineages` の登録順の 0 始まりの番号 n）
| 段 | 4〜5 段の系統 | 3 段の系統 |
|---|---|---|
| 1 | アクセサリ | アクセサリ |
| 2 | n が偶数なら手、奇数なら足 | n が偶数なら頭、奇数なら盾 |
| 3 | n が偶数なら頭、奇数なら盾 | n が偶数なら体、奇数なら武器 |
| 4 | n が偶数なら体、奇数なら武器 | — |
| 5 | 武器 | — |
- 鋼の魔物の系統は、どの段もアクセサリ（既定の特殊効果 `{expPct:50, goldPct:100}`、クセ `{takenPct:25}`）。

**能力値・武器・重さ**（種族 `race` から。主な能力値の重さを使う: 腕力・体力 → 重装、器用さ・素早さ → 軽装、知力・精神 → 布）

| bird 鳥 | 素早さ / 器用さ | 弓 | `spd:30` | `hpPct:-20` |

| plant 植物 | 精神 / 体力 | 鞭 | `regen:true` | `spd:-30` |
| aquatic 水棲 | 体力 / 精神 | 槍 | `hpPct:20` | `spd:-30` |
| dragon 竜 | 腕力 / 体力 | 大剣 | `hpPct:20` | `spd:-30` |
| undead 不死 | 知力 / 精神 | 杖 | 武器 `drain:0.2`、ほか `statusImmune:['death']` | `hpPct:-20` |
| demon 魔族 | 知力 / 腕力 | 刀 | 主が知力なら `magicPct:15`、腕力なら `physPct:15` | `takenPct:25` |

- 特殊効果の 1 つ目は**親和の属性** e から: 武器なら `element:e`、主が知力の品なら `elemBoost:{e:30}`、ほかは `elemResist:{e:0}`。親和が無ければ 1 つ目を省いて、表の 2 つ目だけ。

- 数値の大きさは §3.5・§3.6 の超レアの欄の中に収める。

### 6.3 名前と id
- id: `<接頭辞>sr_<鍵>`。鍵の既定は魔物の id（例 狼の 3 段目 `wolf_3` の手なら `hn_sr_wolf_3`、武器なら `w_<wtype>_sr_wolf_3`）。
- 名前: 「**<その魔物を思わせる言葉>の<品の名>**」、全角 9 字以内。落とす魔物が分かるようにする（例 大牙の狼 → 「大牙の籠手」、白い蛾 → 「月蛾の羽衣」は不可（「羽衣」は他社の品名に近い。§14.3）→「月蛾の薄衣」）。
- 同じ名前・同じ id は作らない（検査 §14）。
- `exclusive` に魔物の id を書く。魔物の `drops.super = {item:<超レアの id>, rate:256}`（鋼 128。成長章 §10.1）。

## 11. 店（34。`R.DB.shops`。id はワールド章 §6.1）

### 11.1 品ぞろえの決まり（規則）
- 店の形はエンジン章 §5.5（`{name, items:[固定品], stock:[{tier, cond?, items}], keepOld}`）。**rules への依頼**: `R.Tier.shopItems` は「`tier ≤ 今のティア` かつ `R.State.check(cond)` が真の段」だけを見る。`keepOld:true` ならそれらをすべて足し、`keepOld:false` なら**配列で最後の 1 段**だけを出す（`items` の固定品はいつも出す）。
- **武器屋・防具屋**（`keepOld:false`）: 今のティアの、その店の系列の品だけを出す（前のティアの品は出さない）。防具屋はティア 3 から `ac_redcloth`・`ac_brooch` も出す。
- **道具屋**（`keepOld:true`）: 道具と補助のアクセサリが、ティアとともに増えていく（共通の 4 段 §11.2）。
- **クリア後**: リュートとビブリアの武器屋・防具屋に、T9 の通常品の段（`cond:{postgame:true}`）を足す。
- 店には**通常品だけ**を置く（レア・超レア・遺物・報酬は置かない。検査 §14）。
- 店の NPC は町の担当が置く（`shop_item` `shop_weapon` `shop_armor` `shop_magic`、`shop:'<店id>'`。ワールド章 §6.1）。`coral_regnas` の商人は cond `{cleared:'r_isles'}`。

## 12. ティア宝箱のプールと、ボスのドロップ

### 12.1 宝箱のティア（規則。rules の `R.Tier.chest` への依頼）
- 宝箱の中身は、開けたときに `R.Tier.pick(DB.pools[def.pool].tiers, T)` で 1 つ引く（重み `w`、個数 `n` 既定 1、お金は `{gold}`）。**T = `def.tier` → マップの `chestTier` → `R.Game.tier` の順で最初にあるもの**。
- マップの `chestTier`: 白の大書庫 `archive_1..6` は 8（どうせ 8 だが明示する）、忘却の底 `oblivion_1..5` は **9**。ほかのマップは書かない。
- プールは 10 段（ティア 0〜9）。
- 固定の中身の宝箱（`item` を直に書く）は作らない（物語に要る物はイベントで渡す。ワールド章 §6.2-8）。例外なし。

(function (R) {
  'use strict';
  const RB = [1, 1, 3, 3, 5, 5, 7, 7, 9, 9];                                   // ティア → レアの帯
  const GOLD = [60, 130, 230, 360, 530, 720, 960, 1200, 1520, 2080];            // 1 つの宝箱のお金

  const S2 = [...S1, ['i_incense', 2], ['i_thaw', 1], ['i_bomb', 2], ['i_horn', 1], ['i_censer', 1]];
  const S3 = [...S2, ['i_elixir', 2], ['i_panacea', 1]];
  const S6 = [...S3, ['i_lifedew', 1]];
  const SUPPLY = [S0, S1, S2, S3, S3, S3, S6, S6, S6, S6];
  const STONES = ['fire', 'water', 'wind', 'earth', 'light', 'dark'].map((e) => `i_stone_${e}`);
  const E = (list) => list.map(([item, w, n]) => (n ? { item, w, n } : { item, w }));
  const EQ = ['weapon', 'shield', 'head', 'body', 'hands', 'feet', 'acc'];
  R.onData(() => {
    const all = Object.entries(R.DB.items);
    const ids = (pred) => all.filter(([, it]) => pred(it)).map(([id]) => id);
    const normal = (T, types) => ids((it) => it.src === 'shop' && it.tier === T && it.line && !it.line.startsWith('charm_') && types.includes(it.type));

      p_seed: P(() => E([['i_seed_hp', 2], ['i_seed_mp', 1], ['i_seed_wp', 1]])),

## 16. 未決事項・注意
1. 超レアの一式（§6.5）の特殊効果は、シミュレーター（成長章 §17.3 C3 の裏ボス）で強すぎたら、`startBuffs`・`autoCounter`・`autoRevive` の品から弱める（数値の構造は変えない）。
2. 防具の系列を 1 部位 6 つにしたので、町の防具屋は 20〜36 品になる（リュートとビブリアは 36〜38）。店の画面が長すぎるなら、menu が「部位ごとのタブ」を付ける（データは変えない）。
3. レア魔物が 24 種より多くなったら、遺物の組を同じ作り方（§3.5 の遺物の欄）で足す。
4. `p_rare` の宝箱を開けたティアが帯の端（偶数のティア）だと、少し先のティアのレアが出る（例 T0 で T1 の帯）。ダンジョンに 1 つだけなので、ご褒美として残す。
5. 報酬の「記録院の銀筆」（ライバル 1 戦目）とレアの `ac_hourglass_*`（補助）は、消費の合計の上限 −50（0.14）に入る。
