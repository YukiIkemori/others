# 09 表現（絵・画面・音）— DESIGN.md 用ドラフト

この章は、**見た目と音のすべての約束**を決める: フィールドの絵（RS1 の雰囲気）、人物の絵、魔物の絵の受け渡し、戦闘画面、フィールドの表示、メニュー、新しい冒険の画面（タイトル・主人公作成・名前入力・仲間選び・酒場）、ゲームオーバーとエンディング、BGM・ジングル・効果音。
中身の数値（ダメージ・確率）とコンテンツ（地方・魔物・技・術・品）は各章が決める。この章は**それをどう描き、どこに置き、何を鳴らすか**を決める。

- 座標はすべて論理ピクセル（256×224）。`(x,y,w,h)` は窓の外枠。文字の `y` は `R.Gfx.text` の左上（`textBaseline:'top'`）。
- 画面の座標は、スクラッチの試作ページ（実物の `gfx.js`・`window()`・DotGothic16・クレストの絵を読み込んだもの）で描いて、目で確かめた値（§1.4）。
- 「P1」は最初の縦の一本道までに必要、「P2」は完成品に必要、「P3」は余裕があれば。**P2・P3 のものは、最初の日から id を登録し、描くまでは「代わり」を返す**（§1.3）。データはいつでも最終の id を書いてよい。
- 他の章と食い違う所は §0 に理由つきで書いた。この章の担当: bui（A3）・menu（A5）・newgame（A6）・art-chars（A13）・art-mons（A14）・art-boss（A15）・art-tiles（A16）・audio（A17）。フィールドの表示の一部は field（A4）、エンディングは story（A19）。

## 1. 共通の約束（全部の絵・画面・音）

### 1.1 画面・文字
- 論理画面 256×224、実キャンバス 768×672（`R.SCALE = 3`）。絵は拡大のにじみなし（`imageSmoothingEnabled = false`）、文字は実解像度で描く。
- 文字の大きさ（§0.2）:
  | 用途 | 大きさ | 全角1字の幅 | 行のピッチ |
  |---|---|---|---|
  | 本文・窓・リスト（`R.Gfx.FS`） | 32/3 ≈ 10.67 | 10.67（半角 5.33） | 14（標準）、11（戦闘の窓・比べる表）、12（所持金の窓） |
  | 大見出し（閃きの技名・章の題・ドロップの札の名前は本文） | 16 | 16 | 20 |
  | ロゴ | 64/3 ≈ 21.33 | 21.33 | — |
  | ごく小さい注記（版の番号だけ） | 16/3 ≈ 5.33 | 5.33 | — |
- 文字の置き場所の y は **1/3 の倍数**にする（1/3 以外の端数だと字形がにじむ）。整数で書けば問題ない。
- 狭い所の名前は `R.Gfx.fitText(str, x, y, maxW, opts)`（横に縮める。縮めても 7px/字 より細くしない）。
- 文字の色: 通常 白 `#ffffff`、補足 灰青 `#c8c8d8`、使えない 灰 `#8c8c8c`、良い変化 緑 `#6ee07a`、悪い変化 赤 `#ff5a4a`、HP 25% 未満 黄 `#ffe45a`、戦闘不能 `#ff4a4a`（`C.dead`）。

### 1.4 確かめ方
- 絵: 各担当の `tools/sheet_*.js`（`--out` は自分のスクラッチ）。ワールドは `sheet_tiles.js --only world,worldmap`、テーマは `--only themes,town`、戦闘背景は `--only bbg`（**4 人分の窓（§5.1）を重ねて描くように直す**。`sheet_bosses` `sheet_rare` `sheet_postgame` の文脈図も同じ）。
- 画面: `node tools/build.js && node tools/shot.js --html debug.html --eval "RPG.debug.quickStart({tier:3})" …`。**撮った PNG は必ず Read で見る**。
- 名前の長さの最悪の組でも撮る: 5 字の名前（`ブリギッタ` `シルヴァン`）、HP 999・MP 99・WP 99、8 字の技名、「金色の」＋8 字の魔物名＋「Ａ」。
- 試作のしかた（この章の座標を確かめた方法。画面の担当が新しい配置を試すとき）: 自分のスクラッチに HTML を作り、`src/core/{ns,input,gfx}.js`・`src/data/*.js`・`src/art/*.js`・`src/systems/battle_fx.js` を読み込み、`@font-face` で `assets/fonts/DotGothic16-Regular.ttf` を読む。`R.Gfx.init(canvas)` のあと `R.Gfx.window/text/fitText` と `R.Gfx.get('mon:…')` で描いて Playwright で PNG にする。

### 1.5 音の約束（全員）
- 呼ぶ側は `R.sfx(id)` / `R.bgm(id, {fade})` / `await R.jingle(id)` だけを使う。
- ジングルは互いを切るので、続けて鳴らすときは `await` する（§10.6）。
- 新しい id はすべて §11 の一覧から選ぶ。一覧に無い id を使いたいときは audio に依頼する。

## 2. フィールドの絵（担当 art-tiles A16。ワールドの配置は world A18、町とダンジョンの配置は reg-a・reg-b・story）

### 2.1 方針（RS1 の雰囲気）
- **ワールドマップ**: 落ち着いた自然の色。深い森は、丸い樹冠がすき間なく重なる濃い緑のかたまり（地面がほとんど見えない）で、森の南の縁にだけ幹と影が見える。山は奥ほど暗く青みがかり、手前ほど明るい岩肌の**稜線の重なり**。海は紺に近い青緑で、白い波頭は小さく少なく。海岸は細い砂の縁と、ところどころ岩の崖。町と町は土色の**街道**で結ばれる。地方ごとに地面の質感がはっきり違う（雪原・砂漠・湿地・灰の荒野・密林）。
- **町と屋内**: 石と木と漆喰のヨーロッパ風の家。屋根の色で町の個性を出す（§2.6）。屋内は SFC ドラクエ5 の密度で、**歩く道は空ける**（Part A2: 詰めすぎない。§2.7 の密度の目安）。
- **ダンジョン**: テーマごとの床と壁（DQ5 風の 3/4 の壁）。地方の伝承に合った素材（森の迷路・木の中・幽霊船・坑道・白い書庫・紙の世界）。
- クレストのタイル・テーマ・飾り・戦闘背景は**すべて使い続ける**（§2.3 の再利用の表）。この章で足すのは、足りない地形・テーマ・飾りだけ。

### 4.1 魔物章で決まっていること（まとめ。変えない）

### 4.2 この章が足す約束（描き方）
| 項目 | 約束 |

| 画素 | 不透明な画素だけ（半透明は使わない）。「透ける」表現は市松の点描（`shade` フィルター・`fine_fade`・霧）。輪郭はほぼ黒（`#120c16` など）で、明るさ 0.09 未満の色は色替え・`tint` で変わらない（今の `hsvShift` と `goldify` の決まり） |

## 10. 音（担当 audio A17。`src/core/audio.js`、`src/audio/*.js`、`tools/render_audio.js`）

### 10.1 方針
- クレストの音の仕組み（MML・和音の進行・楽器・残響・効果音の部品）とクレストの曲・効果音を**そのまま使い**、この作品に必要な曲と音だけ足す。BGM の作り込みは完成品を見てから（Part A）。**P1 の曲は「場面に合っていて、ループがきれいで、`lint` が通る」ことを最低の条件**にする（1 曲 16〜32 小節、40〜90 秒のループ、A/B の対比）。
- 新しい曲は新しいファイルに書く: `src/audio/music_chronicle.js`（BGM）、`src/audio/jingles_chronicle.js`（ジングル）、`src/audio/sfx_chronicle.js`（効果音）。**クレストの曲を作り直すときは、その曲の元のファイルの中で書き直す**（同じ id を別のファイルに書くと、後から読まれた方が黙って上書きする）。
- 未作曲の id は「代わり」を指して登録する（§1.3）。作曲できたら差し替え、`R.Audio.PENDING` から外す。
- id の一覧は 3 か所（この章 §11、`tools/render_audio.js` の `BGM JINGLES SFX`、qa の `validate.js`）で同じにする。`jobup` は一覧から外す（定義は素材として残してよいが、呼ぶ所は無い）。
- **他社の曲のメロディを写さない**（Part A）。クレストのメインテーマ（`THEME`）はスタジオの持ち物なので引用してよい。

### 10.2 メインテーマ「語り部の主題」（新しい 4 小節の動機。タイトル・エンディング・ラスボス・ロアの里で使う）
- 注文: ホ短調（Em）→ ト長調（G）へ明るくなる、3/4 拍子、♩= 92 前後。最初の 1 小節に「頁をめくる」ような上りのアルペジオ（ハープ）、動機はフルートかオーボエの歌う旋律で、**4 小節目で長 6 度の跳躍**を 1 回入れる（覚えやすさ）。
- 動機は `music_chronicle.js` の `defs.TELLER`（MML の文字列）に 1 か所だけ書き、曲ごとに移調・拍子・楽器を変えて使う（クレストの `THEME` と同じやり方）。
- クレストのテーマとの関係: エンディングの E7（三人の勇者の話）と `legend`（P2）でだけ、クレストの `THEME.TA` をオルゴールで 4 小節引用する。

### 10.6 呼ぶ側の約束（bui・field・menu・story）
1. ジングルは互いを切る。**続けて鳴らすときは `await`**。戦闘の `superrare` は必ず待つ（§5.8）。`rare` は待たなくてよい。
2. `levelup` は 1 回の勝利で 1 回（§5.10）。控えの人には鳴らさない。
3. 閃き: `R.sfx('glimmer')` のあと、次の `fx` の効果音まで 36 フレーム以上あける（§5.7）。
4. 宝箱・`ev.give` のジングルは品の種類と grade で選ぶ（§6.3）。`ev.clearRegion` のページは `silent`（`chapter` のジングルと重ねない）。
5. 属性の効果音は `DB.elements[el].sfx`（光は `light`）。
6. 酒場の画面を開いたら `R.bgm('tavern', {fade:20})`、閉じたら `ev.bgm()`（マップの曲へ）。
7. `R.Audio.pushBGM` はジングルを切る。戦闘の入りでは、先に鳴っているジングル（`keyitem` など）を待ってから戦闘に入る（イベント担当）。

## 14. 未決事項・注意
1. **既定の窓の色 `ink`** は lead の確認が要る（クレストは黒）。黒のままにするなら、下の縁の札の地の色（`fill2`）の約束だけ残る。
2. **RS1 の色の段（§2.2）**は町・ダンジョンの床と壁にも少し効く（`PAL` を共有している）。町が暗すぎると感じたら、`tgrass` と町のテーマだけ元の値に戻してよい（ワールドの値は変えない）。
3. 地方の町のテーマ（§2.6）はワールド章 §6.1 の「theme は town」を読み替える。ワールド担当と lead の確認が要る（描かれるまでは `town` の絵なので、壊れない）。
4. 閃きの待ち時間（最低 36 フレーム）は、プレイテストで長いと感じたら 30 まで縮めてよい（効果音が技の音に消されない下限）。
5. 大きいボスの沈め方（§0.9）は、ボスの絵ができたら文脈図で確かめる。顔が隠れるボスは、その絵の中で顔を下に描き直す（沈め方の式は変えない）。
6. 文字を横に縮める所（`fitText`）は字形が少しにじむ。5 字の名前はどの窓でも 52〜54px に収まるように作ってあるので、縮むのは長い品の名前・魔物の名前だけ。
7. 2 列の魔物の並び（§4.2）は、呼ばれた魔物で 256px を超えたときだけ起きる。起きないならコードを入れなくてよい。
8. 図鑑の能力は名目のレベルの値（§7.9）。戦闘ではゾーンのレベルに伸縮する（成長章 §12）ので、図鑑の数値は「目安」として出す（見出しに「（目安）」と書く）。
