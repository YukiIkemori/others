# 日本語テキスト表記ガイド（ルミナス・クロニクル）

**画面に出るすべての文と名前の正**（台詞・メッセージ・メニュー・品や技や魔物の名前・説明文）。`DESIGN.md` も同じ用語で書いてある。クレストの表記ガイド（`reference/CREST_STYLE_JA.md`）を土台に、この作品の仕組み（4 人・2 列・WP・9 枠・閃き・ジョブなし）に合わせて作り直した。`tools/check_text.js` がこのガイドを検査する（§10）。**決まった文（§6・§9）はこのガイドが唯一の正**で、DESIGN の各節はここを参照する（食い違ったらこのガイドに合わせる。第 2 版で決めた）。

---

## 1. 基本
- 対象は 20 歳以上。見た目は SFC 風でも、文は**現代の読みやすい漢字かなまじり**にする。ひらがなだけ・カタカナだけの古い書き方はしない（「たからばこを あけた」→「宝箱を開けた」）。
- **分かち書き（DQ 式のスペース区切り）はしない**。句読点「、」「。」を普通に使う。
- メッセージの窓は **1 行 全角 20 字**（220px。半角は 0.5 字）、**4 行で 1 ページ**。改行は `\n`、改ページは `\f`。長い文は自分で改行する（自動の折り返しに頼らない）。`{hero}` は 5 字として数える。
- 説明文 `desc`: 技・術は 1 行 20 字、品は 2 行 × 20 字（`\n` で改行）。
- 人物ごとの口調を保つ（ベルナは「〜だよ」「〜さ」、オットーは「〜じゃ」、フィーネは「〜わ」「〜の」、ロウェルは硬い言い切り）。
- **主人公はしゃべらない**。主人公の返事は選択肢（「はい」「いいえ」など短い言葉）だけ。町の人は主人公を `{hero}` で呼ぶ。
- 画面に出す日本語は**ソースに直接書く**（ビルドはソースに現れる文字だけをフォントに入れる）。

## 2. 漢字
- **常用漢字**は積極的に使う。常用外の字は、下の一覧の字だけ使ってよい。
- **使ってよい常用外の字**: 杖 槍 斧 鞭 鎧 兜 棍 閃 狼 巫 砦 傭 鷹 槌 吠 沌 翔 淵 獅 鷲 狐 樺 蓮 凪 叉（夜叉だけ）
- これ以外の常用外の字は、ひらくか言い換える:

| 書かない | 書く |
|---|---|
| 噛みつく・噛む | かみつく・かむ |
| 頁 | ページ |
| 水棲 | 水生 |
| 外套 | マント |
| 怒涛の槍 | 荒波の槍 |
| 凍てつく咆哮・咆哮 | 凍える叫び・叫び |
| 埃 | ほこり |
| 雫・飴・軟膏・壺・炸裂 | しずく・あめ・ぬり薬・つぼ・はじけ（はじけ玉） |
| 蛾・叉（三叉）・銛・葦 | 羽（眠り羽の短剣）・三つまた・もり・アシ |
| 黎明・砂塵・縞・焚き火・噂・珊瑚 | 朝焼け・砂けむり・しま・たき火・うわさ・サンゴ |
| 麻痺・痺れ | まひ・しびれ |
| 鉤爪 | かぎ爪 |
| 蒼 | 青 |
- 「**蘇生**」は仕様書の中だけの語。画面では「**生き返らせる**」「生き返った」と書く。
- 読みにくい語は言い換える（退き口 → 逃げ上手）。
- 「黄泉（よみ）」「冥府」「極夜」は読める範囲として使ってよい。

## 3. 表記の統一
**正の書き方**（品・魔物の名前と台詞のすべて）
| 正 | 使わない |
|---|---|
| 鎧・兜・靴・頭巾・冠 | よろい・かぶと・くつ／ぐつ・ずきん・かんむり |
| 眼鏡・片眼鏡・棍棒・鉢巻き | めがね・片めがね・こん棒・鉢巻 |
| 戻る・外す | もどる・はずす |
| 閃き・閃く | ひらめき・ひらめく（画面ではひらがなにしない） |
| 清め・守り | 浄め・護り |
| 〜よけ（毒よけ・眠りよけ） | 〜除け（ただし「魔除け」だけは漢字） |
| アクセサリ | アクセサリー（長音なし） |
- **魔物の名前の動物はカタカナ**（オオカミ・ヘビ・トカゲ・ネズミ・コウモリ・フクロウ・サソリ・マンモス）。**品の名前の熟語は漢字でよい**（狼革の胴着・蛇骨の弓・月狼革の鞭）。
- **三点リーダー**は必ず 2 つ「……」。文末は「……。」（「……！」「……？」はよい）。台詞がそれだけのときは「……」。
- **全角スペース**は次の 2 つだけ: (1)「！」「？」のあとに文が続くとき（「よくぞ来た！　語り部さん。」）、(2) UI で項目を並べるとき（「最大HP+14　最大MP+2」「ファロス灯台　2階」「ひだまり　×3」「隠し通路　3/15」「リピート　Bで解除」「攻+12　術+5　守0」）。それ以外（分かち書き）には使わない。
- **数字**: 値・個数・回数・階・Lv・ゴールド・歩数・％は**半角数字**（「12のダメージ」「300ゴールド」「100歩」「2階」「Lv34」「35%」）。台詞・物語の年月や言い回しは漢数字やかなでよい（「三日」「三百年」「ひとつ」「八つの伝承」）。同じ画面の中ではそろえる。
- **記号**: 感嘆・疑問は全角「！」「？」。波線は「〜」（U+301C）。ダッシュは「――」（2 つ）。「♪」のあとは全角スペース。
- 仕様書の表の中の「」はデータに含めない。表の「／」と「<br>」は、データでは `\n` にする。

## 4. 状態・強化・耐性の言い方（`desc`・メッセージ・`autoDesc`）
| 状態（id） | 名前 / 印 | 相手にかけるとき（desc） | 効かない（無効） | かかりにくい（軽減） |
|---|---|---|---|---|
| 毒 `poison` | 毒 / 毒 | 毒にする | 毒が効かない。 | 毒にかかりにくい。 |
| やけど `burn` | やけど / 焼 | やけどを負わせる | やけどが効かない。 | やけどにかかりにくい。 |
| 眠り `sleep` | 眠り / 眠 | 眠らせる | 眠りが効かない。 | 眠りにかかりにくい。 |
| まひ `paralyze` | まひ / 麻 | まひさせる | まひが効かない。 | まひにかかりにくい。 |
| 凍結 `freeze` | 凍結 / 凍 | 凍らせる | 凍結が効かない。 | 凍結にかかりにくい。 |
| 気絶 `stun` | 気絶 / 気 | 気絶させる | 気絶が効かない。 | 気絶にかかりにくい。 |
| 混乱 `confuse` | 混乱 / 混 | 混乱させる | 混乱が効かない。 | 混乱にかかりにくい。 |
| 沈黙 `silence` | 沈黙 / 黙 | 術を封じる | 沈黙が効かない。 | 沈黙にかかりにくい。 |
| 暗闇 `blind` | 暗闇 / 暗 | 目をくらませる | 暗闇が効かない。 | 暗闇にかかりにくい。 |
| 即死 `death` | 即死（効果の名） | 一撃で倒す | 即死が効かない。 | 即死にかかりにくい。 |
| 良い状態 | 再生 / 再・加護 / 護・反撃の構え / 構・身軽 / 軽・かばう / 守 | 再生の状態にする・加護で守る・反撃の構えをとる・身軽にする・仲間をかばう | — | — |
- 追加効果の文は「〜ことがある。」（「眠らせることがある。」「術を封じることがある。」）。短い形は「眠らせる。」。
- **使わない形**: 「眠りにする」「まひにする」「沈黙にする」など、状態の名前＋「にする」（毒だけは「毒にする」でよい）。「〇にならない」（→「〇が効かない。」）。
- 複数は「・」でつなぐ（「眠り・混乱・沈黙が効かない。」）。
- 強化・弱体の対象は **攻撃力・守備力・術力・術防・素早さ**。「〜を1段階上げる」「〜を下げる」。
- 属性の耐性: 「火のダメージを減らす。」（0.5）、「火の攻撃を受けない。」（0）、「火の攻撃を吸い取る。」（−1）、「ただし火に弱くなる。」（弱点のクセ）。
- クセは「ただし〜」で書く（「ただし守備力が下がる。」「ただし術が使えない。」）。
- 倒れた人は「**戦闘不能**」、倒れた人を戻すのは「**生き返らせる**」。

## 5. 台詞の書き方
- **町の人・店員・宿屋・船乗り**: 話者名もかぎかっこも付けない。本文だけ。
- **固定キャラ**（ベルナ・ロウェル・フィーネ・ラザロ・虚ろの王・ネムレア）が**2 人以上話す場面だけ**「名前「本文」」の形にする。1 人しか話さない場面では付けない。フィーネは物語のフラグ `st_t3` の前は「少女」と表示する。手紙は「手紙「本文」」でよい。
- 仲間は個別の物語を持たないので、物語の台詞に仲間の名前を前提にしない（加入の台詞 `joinLine` と後日談 `epilogue` だけ）。
- **プレースホルダー**（直書きしない。表示のときに置き換わる）:
| 書き方 | 置き換え後 |
|---|---|
| `{hero}` | 主人公の名前（プレイヤーが決める。5 字まで） |
| `{leader}` | 出撃中で生きている先頭の人の名前（宝箱・扉など、その場の人の動作） |
| `{g:男形\|女形}` | 主人公の性別で選ぶ（例 `{g:坊や\|お嬢さん}`） |
| `{name}` `{user}` `{ally}` `{item}` | 戦闘・メニューの文の中の、その人・その品（コードが置き換える） |
- クレストの `{yuki}` `{non}` `{metem}` は使わない。
- 主人公の呼び方は `{hero}`、全員を指すときは「{hero}たち」。
