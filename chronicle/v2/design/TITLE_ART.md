# TITLE_ART — タイトル画面の一枚絵（組み込みの仕様）

MODERN_UI §6.1 のタイトルを、描いた一枚絵に置き換えるための仕様。対象は `src/screens/title.js` の `drawBg()` と題字の部分。命令の一覧、つづきからの札、ボタン表示は今のままでよい。

- 見本（完成形のモック）: `design/shots/title_art/mock_title_wide.png`（1920×1080）と `mock_title_phone.png`（1170×2532）
- 構図の比較: `design/shots/title_art/compositions.png`
- 素材: `assets/title/`（下の表）。作り直しの手順: `chronicle/design/art_ref/gen/title/build_title_assets.py`、モックは `mock_title.py`。生成したままの絵とプロンプトは `gen/title/raw/` に置いてある（git に入れない）。

## 1. 絵の中身

- 高い岩場に立つアルン。等身は写実寄り。ランタンを高く掲げ、夜の谷を見下ろしている。赤いマフラーと上着の裾は右へなびく。
- 谷には **八つの大灯火** が奥へ S 字に並ぶ。灯台、千年樹、鐘楼、雪の峰、砂漠の町、鍛冶の炉、ほか 2 つで、どれも細い光の柱を空へ立てている。右奥には火山、左の水平線には月と海がある。
- 絵柄は油彩風の描き込んだ一枚絵。深い藍の夜に、琥珀色のランプの光を当てる。
- 仲間は描かない（A36）。

### 描き方
- 横持ちの論理画面は 960×540 で、横長の画面では最大 1260×540 になる。絵は **cover**（短い辺に合わせて拡大し、はみ出しを切る）で置く。切るときは焦点 `focal.face` が画面に残る向きに寄せる。視差の分として、全体を **1.03 倍** にして中央に置く。
- 縦持ちは 540×(〜1260)。`phone_*` を同じように cover で置く。縦横比は 390:844 と同じ。
- 横持ちで、画面の縦横比が 1.6 より小さい（4:3 に近い）ときも cover でよい。右端のマフラーの先が少し切れるだけで済む。
- 題字: `logo_safe` の左上に、幅 `w × R.W` で置く（横持ち x .05・y .06・w .40、縦持ち x .06・y .06・w .88）。題字の中心の下に、半透明の暗い楕円（rgba(4,6,18,.47)、ぼかしは幅の 8%）を敷く。
- 命令の位置:
  - 横持ち: x .075・y .655 から。行の高さ 44（論理）、文字 21。
  - 縦持ち: x .15・y .75・幅 .70 の、ガラスの札（UIK.panel a .47）の中に中央揃え。行の高さ 50、文字 19。
  - 横持ちで y .655 から始めるのは、灯台の灯（x .155・y .63）を命令の枠で隠さないため。
- つづきからの札: 横持ちでは命令の右（`continue_card_safe`、x .30・y .655）。縦持ちでは命令の札の上。
- 暗がりは今の「左の暗がり」を置き換える。
  - 横持ち: 左から 48% までを、最大 .55 で暗くする。さらに左下（y .55 から下）を最大 .75 まで重ねて暗くする。
  - 縦持ち: 上 25% を最大 .35、下 34% を最大 .6 で暗くする。
  - 色は #060814。
  - 絵そのものはもう暗いので、これ以上濃くしない。
- `© Studio Metem  ver` とボタン表示は今の位置のまま。縦持ちでは `R.safe.b` の分だけ上げる（ホームバーを避ける）。

## 3. 動き（視差・光・粒）

**視差**
- 各層を `offset = amt × parallax × 最大 px` だけずらす。最大 px は論理座標で横 7 px、縦 5 px（1920 の絵では 14 px と 10 px にあたる）。
- `amt` の決め方:
  - マウスやカーソルのある所では、ポインタの位置（−1〜1）を 0.6 秒でならした値にする。
  - タッチや、ポインタがないとき（ゲームパッドなど）は、`sin(t/9000)` 程度のごくゆっくりした揺れを横 0.6 倍・縦 0.3 倍で使う。
- 縦方向のずれは横の半分にする。
- 空の層だけは、さらに 60 秒で 1% 拡大し、戻す（ゆっくりしたズーム）。

**光**（すべて `lighter` で足す。`R.UIK.glow` で足りる）
- ランタン（`lantern`）:
  - 半径 0.16H の琥珀 [255,170,80]、強さ .35。
  - 芯は半径 0.035H の [255,230,170]、強さ .6。
  - 強さに揺らぎを掛ける: 0.9 + 0.1 × (sin(t/130) × .5 + sin(t/370+1.3) × .5)。点滅を減らす設定では揺らぎを 1/3 にする。
- 八つの灯火（`beacons`）:
  - 半径 0.018H の [255,190,110]、強さ .35。
  - 灯火ごとに位相をずらし、4〜7 秒の周期で ±25% ゆっくり瞬かせる。
  - 光の柱は絵に描いてあるので足さない。
- オーロラ: 足さない（絵にある）。どうしても動きがほしければ、右上に `key` の空の部分をもう一度重ね、`lighter` の不透明度 .06〜.12 を 8 秒の周期でゆらす程度にとどめる。

**粒**（岩場・主人公の層の上、題字の下に描く）
- 火の粉（ランタンから）:
  - 同時に 20〜28 個まで。ランタンの位置から生まれ、上と右へ 12〜30 px/秒で昇りながら、1.5〜3 秒で消える。
  - 大きさ 0.6〜2.2 px（論理）。色 [255,180,90]。ぼかした光と芯の点で描く。
  - 風に合わせて、横へ +8 px/秒で流す。
- 蛍:
  - 14 個ほど。範囲は横 x .55〜1・y .72〜1（岩場の草）と、x 0〜.5・y .75〜1 に少し。
  - 色は青緑 [170,240,210] を 2/3、琥珀を 1/3。
  - 動きはリサージュ曲線で ±14×9 px。明るさは 2〜4 秒の周期で .25〜.6 を行き来する。
  - 今の title.js の蛍の作りをそのまま使ってよい。範囲と数だけ変える。
- 流れ星（任意）: 20〜40 秒に 1 回、左上の空を 0.4 秒で横切る。題字には重ねない。
- 動きを減らす設定（`reduceMotion`）: 視差・ズーム・流れ星を止める。火の粉は 8 個まで、蛍は止めて置くだけにする。

**動く飾り**（持ち主 2026-10-04「静かに生きているタイトルに」。`title.js` の `AMBI`・`drawAmbient`）
- 雲ともや: 空の層の中の雲の帯（月のまわり）と谷のもやを、明るさで抜いて切り抜き（起動して 1 回）、land の層の上・岩場とアルンの下を右へ 2〜7 論理 px/秒で流す。左右を返した物も混ぜる。切り抜けないときは焼いた柔らかい絵。
- 灯台の光の帯: 海辺の灯台（灯火 0）と遠い星の塔（灯火 7）から、16 秒で一回りする帯。遠いのでほぼ水平で、奥を向くと縮んで水平線へ上がり、手前を向いた一瞬だけ灯がまたたく。命令の一覧の枠の上には掛けない。
- 月の道のきらめき（海の細い横線 30 本ほど）、谷の光の粒（9 個、ゆっくり昇る）、火山の火口の明滅（7 秒）、ランタンの光の輪の息づき（5.2 秒で ±6%）。
- 画面全体を毎フレーム塗り直す仕事は足さない。動きを減らす設定では雲ともやを止めて置き、光の帯・きらめき・粒は出さず、出てくる順もやめて 0.6 秒のフェードだけにする。

## 4. 出てくる順（フェードイン）

起動して最初に出すときの順。2026-10-04 に持ち主の「短く 2 秒ほど」で、同じ並びのまま全体を約 2 秒に詰めた（今の時刻は `title.js` の `INTRO`: 空 0〜1.0 秒、灯火 0.3 秒から 0.07 秒おき、岩場とアルン 0.5〜1.2 秒、題字 0.9〜1.6 秒で 12 px 上がる、光の筋が題字を 1.15〜1.95 秒で渡る、命令 1.5〜1.9 秒）。下の表は元の 3.5 秒の順。ほかの画面からタイトルへ戻ったときは、全体を 0.6 秒のフェードだけにする。どのキーでも、残りをとばしてすぐ操作できるようにする。

| 時刻 | 出来事 |
|---|---|
| 0.0 秒 | 真っ黒。BGM `title` を鳴らし始める（下の §5） |
| 0.0 → 1.6 秒 | 空と谷が黒から現れる（sky・land の不透明度 0→1、ease-out）。空は 1.04 倍から 1.03 倍へ寄っていく |
| 0.6 秒 | 八つの灯火が **左の灯台から奥の塔まで、奥へ順に** ともる。間は 0.12 秒で、1 つずつ強さを 0→1 にし、ともる瞬間だけ 1.4 倍に光らせてから戻す。題の「八つの灯火」を見せる所 |
| 1.4 → 2.4 秒 | 岩場とアルンが現れる。ランタンの光は 0 から一度 1.2 倍まで膨らませ、1.0 に落ち着かせる。火の粉を出し始める |
| 2.2 → 3.2 秒 | 題字が現れる。不透明度 0→1、下から 8 px 上がりながら。題字の上の 8 つの炎は、ここでもう一度左から順に 0.05 秒おきに光らせる（題字の上に光を足すだけで、画像は分けない） |
| 3.0 → 3.5 秒 | 命令と下のボタン表示が現れる。命令の行は 0.06 秒おきに順に出し、ここで操作できるようになる |
| 以後 | §3 の動き。蛍は 3.0 秒から出す |

## 5. BGM の入り

- 曲は今の `title`（`music.js` の主題「ひかりの もんしょう」、`R.Audio.bgm('title', …)`）を使う。
- 初めて起動したとき: 0.0 秒から **1.2 秒のフェード** で入る。最初の強い拍は、灯火が順にともり終わる所（1.6 秒前後）に合わせると気持ちよい。曲の頭が合わなければ、灯火の方を曲に合わせる。
- 今の `R.Flow.title()` はフェード 600 ms を使っている。初回だけ 1200 ms にする。
- 灯火がともる音: 灯火ごとに鈴か焚き火の小さな音を重ねてもよい。無くてもよい。音量は BGM より十分小さくし、8 回が続けて鳴っても耳に障らないようにする。
- 決定したとき（はじめから）: ランタンの光を 0.3 秒で 1.6 倍に膨らませてから、全体を暗転する（260 ms、MODERN_UI の画面切り替え）。BGM は 800 ms でフェードアウトする。

## 6. 読み込みと失敗したとき

- 横持ちで要るのは `wide_*` の 4 枚と `logo`、縦持ちで要るのは `phone_*` の 4 枚と `logo` だけ。向きが変わったときにもう一方を読む。
- 読み終わるまでは、今の手描き（コードの）背景と文字の題字を出す。読めたら 0.6 秒で絵に切り替える。
- 層が 1 枚でも読めなければ、`key_*` 一枚だけで出す（視差なし）。光と粒は同じように足す。
- 題字の画像が読めなければ、今の文字の題字（R.TITLE の金のグラデーションと、英字の Cinzel）を出す。

## 7. 題字の確認

- 本題「ルミナス・クロニクル」（中黒を含めて 10 字）と英字「LUMINOUS CHRONICLE」は、生成した文字をそのまま使っている。どちらも原寸で 1 字ずつ見て確かめた。
- 副題「〜八つの灯火〜」は、生成した文字の「八」に余分な画があった。その部分を消し、Shippori Mincho B1 ExtraBold（Google Fonts、SIL OFL）で組み直して、金色で焼き込んである。
- 題字の上のランタンと 8 つの炎は、八つの大灯火を表す飾り。
- 字を変えるときは `build_title_assets.py` の `logo()` を直す。
