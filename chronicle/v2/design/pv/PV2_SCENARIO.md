# PV 第2弾「名前を呼ぶ物語」 台本案（約2分）

持ち主 2026-10-01「映えるエモいやつ2分ぐらいで。前回とは違う見せ方で引き込まれる感じの。戦闘で同じ敵を使わない。歩き方・歩く場所に気をつける」

## 前回（第1弾）との違い
| | 第1弾 | 第2弾 |
|---|---|---|
| 見せ方 | 機能の紹介（FIELD・閃き・合成術…の見出し） | 物語で引っぱる（声と音楽が主役。見出しはほぼ出さない） |
| 舞台 | 序章と迷いの森だけ | 森より先の7地方と書の都（序章・森の絵は使わない） |
| 主人公 | アルン（男・剣） | リーネ（女・術剣士）。新しい顔の絵を出す |
| 仲間 | セルマ・ティッタ・テオ・ヴィオラ | シグレ・ザフィラ・ロウガ（＋戦闘でノエラ・ドッカ・イルゼ） |
| 戦闘 | 森の同じ魔物を何度も | 1カット1ボス・同じ敵と同じ背景は二度出さない |
| 合わせ目 | ふつうの切り替え | 本のページがめくれる（「忘れられた伝承を書き直す」話なので） |

## 守ること（撮影の決まり）
- **敵**：どの敵の組も1回だけ。第1弾の敵（森の雑魚・狼の群れ・ページ食らい）は使わない。背景も1カットに1つ。
- **歩き**：道の上を、道の向きに歩く。壁や水に食い込まない・行ったり来たりしない・止まってすぐ歩き出す等のカクつきなし。
  仲間は一列でついてくる。カメラは進む先を少し多めに見せる。歩く場所は全部ちがうマップ（同じ道を二度撮らない）。
- **台詞**：すべてゲームの中の声と文そのまま。大きなネタばれ（フィーネの正体・記録院長・終盤の味方の寝返り・結末）は入れない。
- 画面の手引き（HUD・行き先の札・「TEST」）は出さない。会話の窓は、声のあるカットだけ本物を出す。

## 撮る前に確かめること
- 白紙になる演出：ゲームにある「白紙になりかけた町」（ビブリア）の見た目を使えるか。無ければ仕上げで白く飛ばす。
- 八つの灯がともる地図：一枚絵の地図に光の柱を順に出せるか（クリア後の状態を順に当てて撮る）。
- 曲の頭出し位置（legend・sorrow・boss2・dawn）。
- 歩きのカットは、撮った後にコマ送りで壁・水への食い込みと足の運びを見る。
