# 鐘のならない修道院（HD-2D方式の試作）

`chronicle2/monastery/`（Blender で描き出した一枚絵の上を歩く版）と見比べるための別案です。
こちらは背景を**立体のまま、ブラウザの中でその場で描きます**（three.js）。石や草の模様は主人公と同じ大きさのドットで描き、
光と影、奥と手前のぼかし、灯のにじみを今風にかけ、96ドットの主人公を立て札のように立体の中へ置いています。

- `dist/index.html` 公開するページ（1ファイル。three.js だけ CDN から読みます）
- `src/` 元になるコード。`src/page.html` がページの見た目、`src/core/` が土台、`src/areas/` が修道院の各所
- `tools/` 手元で動かす、スクリーンショットを撮る、公開用にまとめる
- `CONVENTIONS.md` 全体の決まり（英語。座標、縮尺、光、色、確かめ方）
- `AREAS.md` 各所を作るときの決まりと地図

## 動かし方

```
node tools/serve.mjs 8765          # http://localhost:8765/play で遊べます（src を毎回組み立てます）
node tools/shot.cjs "play?at=0,-20&k=1" shots/x.png    # 画面を撮る（ソフトウェア描画なので1枚 30 秒ほど）
node tools/build.mjs               # dist/index.html を作る
```

`/play` に付けられる主な指定: `only=nave,tower`（その場所だけ建てる）、`at=x,z`（主人公をそこに置く）、`walk=1`（歩ける範囲を点で表示）、
`free=px,py,pz,tx,ty,tz`（自由なカメラ）、`nopost=1`（ぼかしやにじみを切る）、`k=1|1.5|2`（描く細かさ）、`t=秒`（時間を止める）。

## 決まりごと（要点）

- 向きは x が東、y が上、z が南（北は -z）。カメラは常に北を向いて 36 度見下ろし、回りません。
- 主人公の身長が 3 単位。模様はどこでも 1 単位 32 ドット。画面は 16:9 で 540p の k 倍（k は 1、1.5、2）なので、主人公の 1 ドットがちょうど k ピクセルになります。
- 色は `src/core/pal.js` の色見本だけを使います。彩度は低く、影は深い紫がかった色、光は暖かいクリーム色。黒い輪郭線は使いません。
- 立体に貼る模様に展開図（UV）は要りません。面の向きから自動で貼り、ドットをくっきり出します（`src/core/mat.js`）。
- 歩けるのは、道（`src/core/world.js` の `PATHS`）と、各所が「床」と宣言した場所だけです。壁や墓石は「通れない」と宣言します。

## 主人公の差し替え

`tools/pagegen.mjs` の `HERO` に、シートの画像と説明（1コマの大きさ、足元の位置、1コマの時間、各コマの灯の位置）を書きます。
シートは横4コマ（立ち、片足、通過、逆足）、縦は 下・左・右・上（8方向なら続けて 左下・右下・左上・右上）。
灯の位置が書かれていないシートは、明るい暖色のかたまりを自動で探します。
